正常化利润重构（估）： - 2025年净利722亿中含碳酸锂库存收益/减值转回的周期性成分（2026H1毛利率23.9% vs 2025全年26.3%，锂价回落已开始挤压毛利率——2026-10-09东财fin）。 - 正常化基准取2026E一致预期961亿（同花顺36家，2026-09-25）与自估区间下沿的交集：正常化盈利约900–960亿，对应管理层"2026–2030年25–30%复合增速"口径（钛媒体2026-03-09转引业绩会）的2027年约1,150–1,200亿。 - 分部正常化（估）：动力~500亿 + 储能~250亿 + 材料回收~80亿 + 其他~130亿 ≈ 960亿，与一致预期互洽。

ROIC / 现金流 / 营运资本 / 杠杆（东财F10/GBALANCE，2026-06-30）： - ROIC（年化）：2025全年15.3%，2026H1年化约16.5%——持续高于WACC（估8–9%），是产业链中唯一"多年创造经济利润"的公司。 - OCF：2025年1,332亿；2026H1 602亿（每股13.0元）。Capex：2025年423亿；2026H1 251亿。FCF 2025年909亿、2026H1 351亿，FCF/净利>100%，盈利含金量极高。 - 营运资本：存货周转89.4→96.6天（2025FY→2026H1，锂价上涨周期备货+储能交付周期拉长，Q4存货945亿历史新高，钛媒体转引）；应收周转53.6天（改善中）；资产负债率63.7%但货币资金3,720亿 vs 有息负债（短借209+长借743+债券285）约1,237亿，净现金约2,480亿（估）——账面杠杆是"负杠杆"，产业链占款（应付款）构成真实资金优势。 - 结论：财务质量A级。2026H1毛利率下滑1.5–4pct是唯一瑕疵（锂成本传导时滞），已被量增+结构对冲。

1.3 恩捷股份：2025年低点是否周期底部

判断：是周期底部，且是深度出清底部。证据链： - 归母净利轨迹：2021年27.2亿 → 2022年40.0亿（顶）→ 2023年25.3亿 → 2024年-5.6亿（毛利率11.1%）→ 2025年1.4亿（毛利率18.8%）→ 2026H1 8.2亿（毛利率29.9%）——毛利率从11%修复至29.9%，价格战实质结束（SMM 2026H1：基膜价格自底部+8%）。 - 2024–2025连续两年微利/亏损迫使全行业停止扩产：恩捷capex从2023年78.2亿 → 2025年17.3亿 → 2026H1 5.8亿（-67% vs 2025H1，估），在建工程从2025-03的62.9亿降至11.6亿——扩产周期终结是价格修复的先决条件，已满足。 - 格局归拢：恩捷收购爱思开（2026-05-28）、11.5亿回购湖北恩捷45%股权（2026-09-27公告）——龙头回收产能，与2022年扩产潮反向操作。 - 修正后利润可持续性（估）：2026H1的8.2亿含稼动率恢复+涨价双击；正常化取2027年18–20亿（对应隔膜出货增长15–20%+价格温和上行、毛利率28–30%），约为2022年顶点的一半——考虑到2022年40亿包含极端供不应求溢价，18–20亿作为"出清后中枢"合理，但需验证。

ROIC / 现金流 / 营运资本 / 杠杆： - ROIC：2022年15.9% → 2024年-0.9% → 2026H1年化约5.3%——修复中但仍低于WACC，尚未恢复价值创造；这是44.5x PE-TTM下最刺眼的事实。 - OCF持续为正（2025年11.4亿 vs 净利1.4亿——折旧重资产属性，OCF远好于利润）；2026H1 FCF +5.9亿（2023年以来首次转正）。 - 营运资本：应收周转162.9天（2026H1），虽较2024年的227天大幅改善，但在三家中最差——对电池厂议价权弱是结构性问题。存货周转62.3天（从2025H1的110天改善）。 - 杠杆：这是真正的风险点——短借76.0亿+长借53.8亿=129.8亿有息负债 vs 货币资金31.6亿，净有息负债约98亿（估），相当于归母权益260.5亿的38%；资产负债率44.2%。固定资产280.9亿（占总资产56%），重资产+净负债，若价格修复夭折则再陷减值循环。 - 结论：财务质量C+→B-（修复中）。OCF健康但净负债重、应收长、ROIC未越线。

二、三情景估值卡片

2.1 宁德时代（300750）｜方法：正常化盈利 + 分部视角，PE区间定价

为何不用DCF：宁德五年维度增速（管理层口径25–30%）与终端（车+储能+AIDC）政策/价格高度不确定，DCF的终值假设会主导70%以上价值（估），伪精确；公司FCF极强且资本回报稳定，正常化盈利×分部合理PE在信息含量上不劣于DCF，且误差可讨论。分部视角意义：其他业务（技术授权，69%毛利率）与材料回收应给高于电芯的倍数。
