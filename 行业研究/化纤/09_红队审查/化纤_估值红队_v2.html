1. 荣盛石化（2处事实/算术错误，4处口径瑕疵）

1.1 事实/算术错误

E1｜TTM归母与PE-TTM自相矛盾（§0 vs json）。报告正文写"1253亿÷TTM归母约53.5亿=23.4倍"；json复核项写 cumulative=59.99, previous_cumulative=6.02 → claimed 53.97，正文§2数据表2025全年8.48+26H1 51.11−25H1 6.02=53.57。三处出现53.5/53.97/53.57三个数。json的cumulative=59.99与全年+半年合计59.59不符，59.99无法由已知数复算出来——该复核项本身算错（59.59−6.02=53.57）。PE核对（1252.6/53.57≈23.4x）结论正确，但底稿中存在不可复算的数字，违反"机械检查可复算"要求。

E2｜"浙石化2021年222亿"与"26H1年化102亿＝与2021H1单半年113亿同级别"两处表述自相矛盾（§2转折二 vs §11）。§2说26H1浙石化82.7亿"与2021H1浙石化单半年113亿同级别"，则2021全年222亿意味着2021下半年仅约109亿——价差脉冲集中在上半年成立，此处尚可自洽；但§11用"2023–2025三年9亿中枢与2021极值222亿两个A级锚点界定完整周期区间，130亿取中偏下"——9亿是荣盛归母口径（含自身板块），222亿是浙石化项目口径，两个不同口径的数字被放进同一个"锚点区间"做中值，属于口径混用。若统一为浙石化项目口径：2023–2025底部约14亿/年（归母7亿÷51%），(14+222)/2=118亿、几何中值约56亿，130亿是算术中值上方——"取中偏下"的说法在统一口径后不成立。这是本份报告核心假设（130亿）最大的口径漏洞。

1.2 口径瑕疵与观点挑战

C1｜"浙石化正常化130亿"无推导规则（重点挑战项①）。报告对恒逸文莱同样问题写了三档裂解价差→利润映射，但对荣盛130亿只给了"高于2023–25实际、低于2021高点与卖方2027E"的定性描述，未给出价差→利润的可复算公式。§3.1敏感性写"浙石化净利±30亿→市值±153亿"，130亿的±30亿恰好覆盖100–160亿，说明作者自己知道锚很弱，但报告未提供PX价差/裂解价差与浙石化净利的回归或映射。建议：至少给出"浙石化单吨净利（2021年约550元/吨顶、底部约35元/吨）×4000万吨×中枢假设"的量纲推导，否则130亿与恒逸22亿面临同样的质疑。

C2｜自身板块正常化12亿的"残差"证据等级自相矛盾。§1表格把自身板块26H1贡献标为"C（倒算残差）→按B-打折"，§3.3又给正常化10–15亿/年，中性取12亿后×10x=120亿占中性市值17%。C级数据按skill规则"不得单独充当核心经营数字和股权价值的事实锚"，12亿×10x=120亿已构成中性档的实质组成部分，打折声明不足以豁免。

C3｜乐观档红线自破。§6.3写"红队提示若负债率仍74%，乐观值应保留约5%折价（-66亿）"——但1318亿的乐观结论未扣减该折价。既然报告自己识别出乐观档少了一层折价，就应在乐观档明确标注1318亿为"未折价上界、调整后约1252亿"，否则红队提示沦为装饰。

C4｜"浙石化ROIC 6–7%（130亿/约2000亿投入资本）"：130亿为项目净利，2000亿为投入资本估算值（B级以下，全文未给来源），7%口径混合了估算分子与估算分母，应标"估算×估算=不可靠"。

1.3 值得肯定的部分

与桐昆同资产每1%权益定价的交叉验证（13亿 vs 14–15亿）是全行业报告里最好的预期差证据；"PB-ROE提示偏宽 vs FCF yield提示不贵"的矛盾被显性写出而非强行调和，符合skill精神。中性705亿的结论在C1补上推导后可维持，红队不要求改结论。

2. 恒逸石化（1处事实/算术错误，4处口径瑕疵）

2.1 事实/算术错误

E1｜敏感性系数与三档利润自相矛盾（§3.1）。报告称"柴油裂解每变动10美元/桶→归母约±12–15亿/年"。但按报告自己的三档：中性（裂解25–35美元，取中30）文莱归母22亿；悲观（10–15，取中12.5）8亿——Δ17.5美元对应Δ14亿，即每10美元约8亿；乐观40美元+为40亿，从30→40美元Δ10亿、即每10美元约10亿。三档自洽的敏感性是8–10亿/10美元，与声明的12–15亿系统性偏差30–50%。用声明值反推，中性22亿要求裂解约35–38美元——已在中性区间（25–35美元）上沿之外。这一矛盾使中性348亿的档位相对自身参数偏乐观一档。按8–10亿/10美元修正，中性文莱利润应约15–18亿，SOTP约285–310亿，中性结论需下修约10–15%。

2.2 口径瑕疵与观点挑战

C1｜"文莱22亿正常化"的推导依据不足（重点挑战项①）。22亿的口径是"中性柴油裂解25–35美元/桶对应"，但没有裂解价差→800万吨×收率×加工费→项目净利的桥。报告给的敏感性（12–15亿/10美元）本是这条桥的斜率，但它与三档不一致（见E1）。修复方式：给出"每10美元×800万吨×约50%柴油收率×70%权益×(1−税)"的显式算式并重新校准三档。22亿隐含的裂解中枢约35美元，高于报告引述的"常态10–15美元"近2.5倍，报告虽有"炼能瓶颈支撑高于历史中枢"的表述，但该表述本身是C级观点（高盛口径），不足以支撑中性档的核心假设。这是四份化纤报告中最需要回炉的一处。

C2｜"+40亿净现金/银行股权"三档共用、无来源。浙商银行4%股权权益法利润3–5亿/年（C级）不入利润但40亿"净现金/银行股权"直接加进三档SOTP。按C级不入锚规则，该项至少应标注"估算，未按NAV法核验银行股权市值"；且恒逸账面资产负债率67.57%，"净现金"表述与67%负债率并存需要解释（文莱项目融资在项目层？）——报告未解释。

C3｜26H1文莱65.21亿为B级媒体转述，全文利润桥以其为最大分项。45.6亿（=65.21×70%）构成归母77%，桥的两端都是B级转述×B级比例的估算，报告标注了证据等级但估值敏感度未降档处理——若65.21亿有±20%误差，中性348亿摆动约±27亿。建议在验证表增加"半年报分部附注原文核对"为最高优先验证项（已有，但排在26Q3之后，建议提为第一项）。

C4｜总股本41.1亿股为"市值÷股价"倒推估算，而转股刚完成、股本漂移。每股结论8.5元建立在一个倒推的分母上。东财每日披露总股本，应直接取数。

2.3 值得肯定的部分

"低PE正是周期顶特征"、26H1 OCF为负揭示库存浮盈、战时特殊分红与当日-7.24%的顶部行为组合——三层周期顶识别是全行业报告中周期分析最完整的示范。框架无需改动，需修的只是E1的敏感性校准与C1的推导链。

3. 神马股份（2处事实/算术错误，3处口径瑕疵）

3.1 事实/算术错误

E1｜PB-ROE的Gordon推导与所引PB区间不自洽（重点挑战项②）。§6.1称"PB-ROE推导内生于ROE假设（r=9%、g=2.5%），三档PB 0.5/0.8/1.05倍与ROE 2%/4%/7%单调自洽"。按Gordon公式 PB=(ROE−g)/(r−g)：ROE=4%→PB=0.23；ROE=7%→PB=0.69；ROE=2%→PB≤0（负值，截为0）。报告实际给的PB是0.5/0.75–0.85/1.05–1.10，全部显著高于公式值（0.8是公式值0.23的3.5倍）。报告要么未真正使用该公式、要么使用了未披露的另一组参数（如g=4.5%、r=10%）。两种r/g下公式值为：g=4.5%、r=10%时ROE4%→PB=0.73、ROE7%→1.62——仍对不上0.75–0.85。"推导内生于参数"的声明与实际数字不符，属算术层面的虚假自洽。修复：披露真实使用的PB-ROE映射方法（很可能是经验倍数而非Gordon），并把"自洽"改为"经交叉调整"。

E2｜中性档"取并集"逻辑破坏PE/PB口径一致性。json底稿写明中性50–61.2亿是"PE口径2.5×20=50亿"与"PB口径54–61.2亿"的并集，但§6.2正文写"取50–61亿"且卡片只给中枢55亿。PE口径（50亿）与PB口径（54–61亿）是两种独立方法的两个估值，不是同一个估值的区间端点——并集得到的是"方法分布"而非"不确定性区间"。更关键的是E1显示PB口径本身推导存疑，用存疑方法的下沿抬高并集下沿，中性55亿中枢偏乐观约5–10亿。

3.2 治理否决的审查（重点挑战项②）——否决成立，但表述需补一处

  • 立案调查（2026-04-24）+累计调减利润1.7亿+立案前5个月警示函，三项A级事实链完整，一票否决的触发条件（"涉嫌信息披露违法违规立案未结"）在skill与主队列规则下均成立。维持。
  • 挑战点：报告同时给C+而非D，理由是"敞口证据硬、行业地位真实"。红队认为逻辑一致（否决的是建仓资格，不是研究价值），但§10升级条件①"结案且无重大处罚→移除否决，可升B-"遗漏了一个必要条件：1.7亿重述后的2024–2025报表最终口径确认。立案了结但报表口径悬置时，72亿净资产基座仍不可靠，不能直接升B-。建议升级条件①改为"结案无重大处罚且经审计重述报表确认"。
  • PB口径另一个未挑战到的点：72亿净资产本身含重述不确定性（在建工程转固滞后正是重述内容，转固滞后直接影响折旧与净资产），报告在§7提了一句"净资产基座可能下修"，但三档36–79亿全部以72亿为乘数——重述风险实际上作用于全部三档而非仅悲观档，应在卡片"最容易错的假设"中明示。

3.3 口径瑕疵

C1｜26H1桥中"−费用合计−6.4"为净额假设、无明细支撑，占毛利7.99亿的80%，桥的精度全押在这一个假设上；建议补2026H1三费/研发实际数（中报有披露，非不可得）。 C2｜"自给降本每兑现500元/吨→归母+1.3亿"敏感性：30万吨×500元=1.5亿毛利→税后1.28亿，算术对；但30万吨销量口径（切片+下游合计）无来源标注，B级以下。 C3｜"十年ROIC中位3.15%"与WACC 7.5–8.5%对比支撑"PB<1合理"——该论断成立，但§6.3乐观档PB 1.05–1.10×对应ROE 7%仍低于WACC 8%，按报告自己的ROIC-WACC纪律，乐观档PB>1与"增量ROIC 5–8%仍低于WACC"（§6交叉验证③）矛盾。报告在§6.3只提示了"行业过剩张力"，未触及与自身纪律的矛盾。

4. 台华新材（0处事实/算术错误，2处口径瑕疵）

C1｜json复核项"台华TTM归母：cumulative=8.56, previous_cumulative=3.25 → claimed 5.31"——按2025全年5.31+26H1 3.84−25H1 3.25应为5.90，json的8.56无法复算（comment自称"估算5.9，用精确累计校验近似"，但8.56≠5.9，占位值本身是错的）。正文用的"约5.9亿/14.6倍"是对的，错误仅在底稿占位数。 C2｜正常化桥中"−景气成分−1.2亿=H1收入×3.5pct×(1−税率)"：33.87×3.5%=1.19×0.85≈1.01亿，报告写1.2亿——要么用3.5pct×(1−15%)=2.98pct口径（≈1.01），要么4.2pct口径（≈1.2），前后取整方向不一致，差异约0.2亿（占正常化H1利润7%）。小错，但该桥是中性6.25亿的直接基础，应统一口径。

除此之外，台华的报告是四份中唯一没有跨口径混用的：中性6.25亿的推导（2023–25中枢5.7亿+量增0.5–0.8亿−稀释）各分项均有出处；"66/再生期权记0"的C级处理是skill规则的正确执行；PB-ROE交叉（1.4–1.7x vs 当前1.54x）与PE档自洽。B-分级与中性81亿结论维持，无需回炉。

5. 跨公司横向审查

  1. 同资产口径不齐：恒逸（文莱70%）与荣盛（浙石化51%）的周期中枢都没给价差→利润的显式映射，且两家的映射精度不对称——恒逸给了敏感性斜率（虽然错了），荣盛什么都没给。同一条PX-柴油价差链条上两家应共用同一套价差情景（报告间也确实没对齐：恒逸中性裂解25–35美元，荣盛PX-原油3000元/吨，两套情景无互校）。
  2. 归母权益基数的口径：荣盛PB-ROE交叉用436亿归母权益（26H1）得1.6x PB，恒逸用约300亿（未给来源）得0.8–1.0x合理PB——两家对"少数股东权益"的处理方向一致，但恒逸的300亿是全篇唯一无来源标注的资产负债表数字。
  3. 周期顶纪律执行不一：恒逸"禁用26H1年化118亿"、荣盛"禁用102亿"执行到位；神马对2026H1年化1.3亿的处理（"偏低，取2.5亿"）实际是下修外推，方向相反但合规；台华中性6.25亿低于2026E年化，执行最好。
  4. 折现一致性：三家800V报告统一r=9.5%两年折回；化纤四家SOTP/PE均未折现（估值年2027E直接给现值）。恒逸乐观"回归时点2027年内"与中性一致，尚可；荣盛"2027–28年回归"却未折现，与同批800V报告的标准不一致——若按r=9.5%折回1–2年，荣盛中性705亿应折至约590–640亿。建议化纤批次统一补充折现口径声明（或统一说明"SOTP为2027E正常化口径、不折现"的理由）。
