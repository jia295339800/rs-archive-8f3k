0. 结论与估值卡片

一句话结论：江淮当前497亿市值中，裸业务估值仅约150亿（占30%），约347亿（70%）是尊界叙事期权——而现价隐含的成功概率已超过100%（§6.4测算），意味着市场不仅为"尊界成功"付了全款，还为"比完全成功更好"的想象付了钱。证据环境是：S800月销从4376辆跌至367辆（-92%，B）、扣非连亏9年累计超160亿（B）、26H1经营现金流-52.88亿（A）、产能利用率<10%（B）。中性档只值裸估值，期权价值不能按期望定价透支。

1. 这家公司到底做什么？怎么赚钱？

3. 核心变量：真正决定估值的3–5个因素

3.1 尊界全体系月度交付——乐观情景的唯一裁决变量

9月全体系约2600台（V800 2080+S800 520，B）。第三方测算尊界体系需年销7–8万台才能整体盈亏平衡（C）；当前年化约3万台。缺口：销量×2.5，或单车利润结构改变。尚需观测≥3个月才能确认V系列稳态。

3.2 大众安徽权益亏损——占77%的中性情景主导变量

3.3 现金流失血——最硬的证伪项

26H1经营现金流-52.88亿，同比扩大68%，连续两期中报大幅失血（A）。利润可以用非经常项修饰，现金修饰不了。在OCF转正前，任何"正常化盈利"叙事都不具备现金流支撑。

3.4 产能利用率<10%——叙事与实绩的20倍缺口

尊界超级工厂投资约100亿、设计年产能20万辆（A，发布会口径）；至26H1全体系累计交付约1.9万辆，利用率不足10%（B）。按50%产销率的固定成本摊薄生死线，缺口20倍。超豪华品牌按家用车逻辑建产能——这是本案例最重要的资本配置教训。

3.5 事件风险敞口（新增）

10-08 V800刹车踏板支架测试断裂（懂车帝，B）→两跌停→官方声明免费升级已交付车辆。事件本身可控（用户场景无同类故障，B），但暴露了超豪华品牌对单一安全舆情极度敏感的脆弱性——一次事件蒸发市值约70亿。

敏感性（可复算）：中性档市值150–185亿对大众安徽权益年亏损的弹性：每±1亿权益亏损→年归母±1亿；若2027年大众安徽减亏至-5亿（乐观假设），中性档扣非亏损可收窄至-6亿左右，但仍不转正——中性档不存在正利润，估值锚只能是资产。

4. 正常化盈利：报表利润里哪些能够留下？——答案：不存在

正常化归母净利润在当前证据下不存在（与旧版结论一致，保留）： - TTM归母约-16.8亿（25H2 -9.30亿+26H1 -7.49亿=-16.79亿，A级复算；红队v2修正：原"约-32.8亿"系误并入25FY全年-17.03，两处证据均指向-16.8亿，与东财PE-TTM -29.6反推497/-29.6≈-16.8亿一致）；PE-TTM -29.6无意义； - 扣非连亏9年、累计超160亿（B）；26H1扣非-9.91亿仍在扩大； - 26H1利润桥：归母-7.49亿 = 扣非-9.91亿 + 非经常+2.4亿（政府补助/资产处置，B）——非经常依赖属"常年型"，主业不造血； - 亏损结构（B，财经引半年报）：大众安徽-5.78亿（77%）+汇兑收益同比减少3.9亿+销售费用+69%（尊界推广）。约八成亏损是"为未来叙事支付的门票"。

因此本报告估值锚改为：裸业务（商用车底盘+调整后净资产），尊界以期权形式单列（§6.3）。所有单车利润测算（26Q1尊界单车经营盈利0.8万–5.14万元/辆，C级雪球/自媒体）不作估值输入，仅用于§6.4反推市场隐含要求——该用法不依赖测算正确，只依赖"市场定价了某个数"。

6. 三情景估值：裸估值与叙事期权显性分列

方法：PE不可用（TTM亏损、扣非9年连亏），沿用"PB底线+分部情景反推"，v2.0新增期权价值显性测算：中性只给裸估值；尊界期权只入乐观情景，并给出完整测算逻辑与隐含概率反解。

6.1 裸估值（剥离尊界叙事，中性档主锚）

  • 每股净资产≈22.05/4.00≈5.51元→归母净资产约124亿（A口径反推）；
  • 调整项：剔除尊界专属资产（百亿工厂大部分为尊界定制，按0.5–0.7x残值计）→调整后净资产约90–110亿；剔除大众安徽权益（累计亏损资产，计0）；
  • 商用车分部利润量级1–3亿/年（红队R2修正：与23FY全公司归母仅1.52亿的A级序列有张力，无分部披露——数据缺口），给10–15x=10–45亿，作交叉验证不作主锚；
  • 裸估值 = 调整后净资产×PB 1.2–1.5x = 150–185亿，中枢约167亿（PB锚逻辑对标长安"国企整车底"：江淮商用车盈利能力不优于长安乘用车，PB不应更高）。

6.2 悲观：信任危机+V系列证伪

刹车事件发酵为批量退订（B级以上报道）、V系列重演S800冲高回落、尊界全体系月销<1500台、大众安徽年权益亏10亿+、OCF失血延续并触发融资摊薄。资产端进一步减值压力。PB 1.0x×净资产124亿 = 120–125亿，每股5.3–5.5元，较现价-75%~-76%。

6.3 乐观：尊界期权全额兑现（期权只在此档入模）

期权价值测算逻辑（显性）： - 标的：尊界业务对应江淮持有的经济价值；行权条件：全体系稳态月销8000–10000台（年7–8万台，盈亏平衡线之上）+单车归江淮净利2–5万（C级假设）； - 成功态价值 V_success：尊界体系年归母17–20亿（=347亿叙事溢价÷20x宽限PE反解，见§6.4，同时是卖方"内部稳健预期"年销口径下的量级）×PE 20–25x（对成长期品牌给予的宽限倍数）= 340–500亿； - 期权定价采用单期情景树+主观概率（非风险中性，因无可靠波动率与无套利基础，如实声明局限）： - 期权公允价值 = p×V_success + (1-p)×V_fail −（已在裸估值内的基础价值150亿取中值167亿口径调整）； - V_fail = 裸估值中性中枢167亿（期权作废，退回裸业务）； - 主观成功概率 p=30%（依据：V800首月2080台是唯一正观测点、S800已塌、对公未打通、超豪华复购无先例验证、刹车事件脆弱性）； - 期权公允价值（增量） = p×(V_success − V_base) ≈ 0.30×(340−167) ~ 0.30×(500−167) ≈ 52~100亿； - 乐观情景定义为期权全额兑现（p=1）：市值 = V_success = 340–500亿，中枢420亿，每股15.1–22.2元，较现价-32%~+1%。 p 敏感性档表（红队v2建议补充，可复算：期权价值=p×(V_success−V_base)=p×(173~333亿)，V_base=167亿）：

6.4 现价隐含概率反解（证伪核心）

497亿 = p×420 + (1-p)×167 → p = (497−167)/(420−167) ≈ 130%。 即使按乐观中枢上限500亿反解：p = (497−167)/(500−167) ≈ 99%。 即：市场已经为"尊界完全成功"定价了100%–130%的概率——为叙事付全款后仍溢价约30–77亿。这只有在"市场认为Stellantis代工+尊界SUV是第二个成功态"时才勉强成立，而该传闻未获任何官方确认（A，公司公告澄清）。按纪律，传闻阶段一律不计入估值。

三档单调性检查：120–125 < 150–185 < 340–500，中枢122/167/420，档间差≥40%，无倒挂。

交叉验证

①PB：中性档150–185亿对应PB 1.2–1.5x（调整后净资产口径），与长安等国企整车底部估值带一致；现价PB 4.00x在整车板块中仅次于叙事溢价极高的标的。②隐含尊界分部价值：497−167=330亿，对应需年归母13–16亿（15–25x）——恰好是§6.3成功态门槛，即乐观情景已被基本定价（与总表红队既有判断一致）。③现金流支撑：现价对应任何情景的FCF yield均为负（OCF为负），估值100%由叙事与资产预期支撑。
