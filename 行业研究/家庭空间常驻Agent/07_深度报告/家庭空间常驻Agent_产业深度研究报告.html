一、核心结论（一页版）

  1. 【成立】当前全产业链唯一大规模"已验证收入"在清洁/服务机器人整机（科沃斯、石头）与机器人激光雷达（速腾、禾赛）；执行器/灵巧手/减速器环节已验证收入合计年化仅数亿元（拓普机器人执行器占营收0.10%、兆威未达单列门槛、三花无单列），而市值定价已透支3-10年的量产预期——"真利润在整机与感知，真泡沫在执行器概念"。 红队后独立依据：红队对五家财报数字抽查6项全数吻合（A）；IDC口径已按红队要求改写（见结论4）。

  2. 【修正】"扫地机双龙头是最高置信预期差"降格为"合理偏便宜、等待右侧"（采纳估值报告收敛结论+红队裁决）。科沃斯13.9x/石头16.8x按"成熟家电"定价、家庭在场性期权接近免费——方向成立；但中性upside仅0~+28%、悲观-31~-38%开放，且2026年9-10月新增两个独立证据使"家庭在场性"期权兑现概率进一步下调：优必选U1交付受阻（截至9月底仅交付约2,000台）+ 1X CEO公开承认"用户不退货"是2027年最大门槛。科沃斯26H1扣非-6.37%，若Q3继续负增长，中性应下修至230-290亿。

  3. 【修正】双环传动B级重新评估：分拆催化剂已证伪，降为B-并标注重评。红队核实：环动科技分拆上市已于2026-09终止、撤回科创板IPO申请——原估值报告"环动科技分拆上市推进中"表述被证伪，乐观情景"分拆重估+减速器单列溢价40亿"路径整条删除。双环核心催化剂由"分拆重估"改为"机器人收入占比突破12%/人形减速器放量"，估值锚回归电驱齿轮主业（中性330亿维持，催化剂失效使向上期权收窄）。另：7.95亿"机器人减速器及其他"为合并口径、以工业RV为主、人形相关≈0，业务实质不得上色。

  4. 【修正】IDC数据表述改写：原"2025全球人形出货1.8万台、流入私人家庭不足0.8%"中的0.8%无法溯源至IDC原始报告（仅钛媒体二手转述，C级）。改写为可验证表述：IDC公开口径的六大应用场景（文娱商演/教育科研/数据采集/导览导购/工业智造/仓储物流）不含家庭，家庭出货占比接近零（间接推断）——结论方向（家庭占比极小）不变，证据链降级。

  5. 【修正】LOVOT数字修正为"约2万台活跃部署（2026-06 GROOVE X官方公告）"（A级）。原"累计销量破1.5万台"是2025年中旧数字且错切口径——LOVOT为订阅制"活跃台数"而非累计销量。付费意愿真实的方向不变，量级上修。

  6. 【成立】政策主线：工业/康养/特种先行、家庭跟随。三条主线（具身智能入政府工作报告/养老机器人试点32项目/银发经济8部门文件）经红队逐字核实全部属实（A）。银发文件印发日期2025-12-25、公开时点2026-01-13（民政部专题发布会），两时点分开标注，不得混用。

八、分歧与待验证清单（红队五项，单列成章）

  4. 拓普/三花分产品披露：定期报告机器人收入是否单列>10%披露门槛（当前0.1%与零）——期权计价从"数量级"回到"可计算区间"的唯一途径。
  5. 退货率具名数据源：30-40%（匿名平台，C级）需具名平台+样本量+类目明细才可升级；在此之前不得用于任何定量测算。
