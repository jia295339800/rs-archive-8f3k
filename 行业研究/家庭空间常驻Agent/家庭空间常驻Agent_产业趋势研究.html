家庭空间常驻Agent：产业趋势研究

撰写日期：2026-10-12 ｜ 子Agent：产业趋势研究 ｜ 性质：新兴产业链路研究，数据稀缺，凡推测均标注 数据约束声明：本报告硬财务数据以可溯源的公开来源为准（公司招股书/财报、IDC、政府政策原文）；行业媒体与二级转载数据标注"来源/时点"；无可靠来源处明确写"缺公开数据，推测"。

一、概念界定与研究边界

定义：家庭常驻Agent = 长期驻留在家庭环境中、同时具备①持续记忆（跨会话的家庭成员偏好/习惯/情境建模）、②任务执行（物理或数字任务，含长程规划）、③多设备/多本体协同（家电、传感器、机器人本体）三项能力的智能体。

研究范围（纳入）： - 具身形态：家用/陪伴人形机器人（1X NEO、优必选U1、傅里叶GR-3）、轮式家庭机器人（未来不远F2、科沃斯管家机器人）、萌系/情感陪伴机器人（LOVOT、Moflin、墨宝Mobo） - 非具身形态：家庭中枢智能体（小米Miloco 2.0、华为全屋智能"1+3+N"、AI算力中枢硬件如摩尔线程AI中枢） - 混合形态：扫地机/清洁电器向"管家机器人"演进的产品（石头爬楼+伸缩臂机型、科沃斯+OpenClaw）——仅在其叠加了常驻Agent能力时纳入演进观察

研究范围（排除）： - 纯单一功能设备：常规扫地机、拖地机、智能音箱（无跨会话记忆与长程任务能力）、智能门锁等 - 机构场景养老机器人、工业/商用服务机器人（仅作为对照与"先行市场"参考） - 纯线上家庭软件服务（家庭摄像头云服务等）除非作为Agent的数据底座

关键界定判据：是否有"常驻"（7×24或常态开机在户内）+ "记忆"（个性化沉淀）+ "执行/协同"（不止问答）。三者缺二即排除。

二、技术成熟度评估

2.1 大模型端侧化：从"7B勉强"到"30B能跑"

  • 现状：手机行业已从7B端侧模型转向3B为甜点级（vivo 3B多模态推理模型，128K上下文，内存占用约2GB，出词>200 token/s；来源：科创板日报，2025 VDC）。2026年出现路线跃迁：MoE稀疏架构使端侧30B成为可能——vivo 2026年改口，用2-4GB内存激活1-3B参数、调用30B总参数知识（腾讯新闻，2026-09）；开源社区已验证12GB内存手机流式加载Qwen3-30B-A3B（~5 tok/s）。苹果WWDC 2026发布AFM 3 Core Advanced（20B总参/激活约4B）；微软Build 2026发布Aion 1.0 Plan（14B端侧推理+工具调用模型，需40+ TOPS NPU）。
  • 评价：端侧模型能力对家庭Agent的"大脑"需求（理解、意图中控、任务拆解）已基本够用；但长程规划与多步工具调用的可靠性仍不足——手机侧AI助手跨应用执行的安全授权标准尚未建立（vivo周围，2025）。端云协同仍是主流形态，纯端侧长任务尚不可行。推测：家庭中枢非具身Agent在端侧模型上是"能力先行"的，瓶颈在系统权限与生态接入。

2.2 记忆与长程规划：最弱的一环

  • 具备代表：小米Miloco 2.0（2026-06-18发布）以MiMo大模型为核心，明确四模块：通用常识（安全隐患识别）、身份识别（人脸+体态）、家庭记忆（沉淀成员长期习惯偏好）、家庭任务（条件触发升级为可长期运转的复杂任务）。这是国内首个以"能记忆、会识人、懂执行"为目标的家居开源Agent方案。
  • 但行业共识是：真正AI陪伴需要长期记忆系统+情感建模+个性化推理+主动交互，市面产品大多停留在预置对话/接开源大模型的低智水平（21财经，2026-07）。1X NEO的长期记忆与自主性"随使用增长"，但复杂家务仍需远程人工兜底（Expert Mode teleop，autonomy约60-70%，来源：aibusiness.vc，2026-06）。
  • 结论：记忆与长程规划是当前技术成熟度最低、且最难被发布会叙事掩盖的一环。

2.3 具身智能：硬件接近工程可解，"大脑"是数据荒

  • 灵巧手：快速进步。1X于2026-07-09发布25自由度腱驱灵巧手（22驱动+3腕部，指尖触觉感知法向力/接触位置/剪切力，实时防滑检测），号称2026年自产1万台。但WRC 2026现场趋势反而是"舍手去脚"：两指夹爪替代五指、轮式替代双足，以降低成本、提高部署成功率（每经/凤凰，2026-08）——产业验证阶段选择降级形态。
  • 移动底盘/本体：硬件被视为"工程性可解问题"（国内供应链优势，莫刻机器人CEO，WRC 2026）。宇树2025年人形出货5500+台（招股书），小米新人形样机1.7米/66kg/66自由度（WRC 2026，样机阶段）。人形整机BOM成本6自由度机型约8-10万元（2025，钛媒体引述，来源可信度中等），家用经济模型尚不成立。
  • VLA/具身大脑：Google DeepMind于2026年7月底发布Gemini Robotics 2，首次用统一模型控制人形整机全身（拧灯泡、系垃圾袋等家务任务demo），自称"physical AGI里程碑"（The Independent，2026-07-31）。国内"基模公司"（星海图G0.5、破壳）与"场景公司"两条路线并行；许华哲（破壳，2026-03）明确主张：完全泛化短期不可实现，应定义10件事做到极致。机器人进家庭的最大堵点是真实家庭数据荒——自变量+58到家进1000户家庭的目的就是换数据（36氪，2026）。
  • 总体判断：硬件成熟度>感知/操作模型>长程记忆与规划。家庭全任务通用具身Agent在技术S曲线上仍处早期；单任务专用具身智能体（叠衣、传递、收纳、陪护）是当前唯一被从业者普遍认可的落地路径（钛媒体、许华哲、彭志辉观点一致）。

3.2 明确的反向信号（"已验证的未验证"）

  • 退货率：某头部电商AI陪伴/情感交互潮玩7天无理由退货率普遍超30%，爆款峰值40%（21财经，2026-07）——"新鲜感生意"证据。
  • 流入家庭的比例：2025全球人形机器人出货1.8万台，流入私人家庭不足0.8%（IDC，转引自钛媒体，2026）。
  • 从业者口径：智元彭志辉——家庭普及至少还要五年，先用上门订阅+远程兜底试水；宇树王兴兴——家庭端商业化仍在前期探索（均为2026年公开表态）。
  • 场景分布：人形机器人95%供给工业/商业；家庭场景收入占比仅约5%（钛媒体引述，2026）。

六、未来2-3年关键变量与商业化时间表（2026Q4-2029）

关键变量（按影响排序）

  1. 留存与复购数据：U1/NEO首批交付后的激活率、月活、退货率——决定"情感陪伴"是生意还是一波流量（预计2026年底-2027年可见首批真实数据）。
  2. 远程人工兜底经济性：1X式"60-70%自主+teleop"模式的单台人工成本能否随自主率下降（决定租赁/RaaS模式盈亏）。
  3. 真实家庭数据获取速度与具身模型的"ChatGPT时刻"：王兴兴称未来一两年内可能发生（2026年表态）；若发生，单任务→多任务跨越会提前。
  4. 灵巧操作成本曲线：BOM 8-10万（2025）→家用可接受区间（约3万以下？推测）的下降斜率，取决于B端放量摊薄。
  5. 非具身中枢的生态卡位：小米Miloco开源+华为前装+Matter协议渗透，家庭入口可能先被非具身Agent占住，反向定义具身本体的接入标准。
  6. 监管：家庭数据隐私规则、人机安全标准（工信部已在推进检验检测与全生命周期管理）落地节奏。

2-3年内的正确产业叙事（本报告判断）

  • 2026-2028是"数据采集+场景验证"期，不是"家庭普及"期：产业的真实动作（自变量进千户、未来不远租赁、1X teleop、养老32试点）全都在换数据，而非卖产品。
  • 陪伴先行、家务滞后、中枢隐形化：情绪价值是唯一已验证付费意愿；家务被"单任务专用+降级形态"渐进蚕食；全屋中枢（非具身）大概率先于具身本体成为家庭常驻Agent的事实形态。
  • 泡沫与根基并存：一级市场2026年已从追捧Demo转向盯硬件稳定性/工程化/数据闭环（蓝驰曹巍口径）；宇树上市后股价剧烈波动（上市四天市值蒸发约两千亿，2026-08，澎湃）说明二级已开始用真实业绩校验。
