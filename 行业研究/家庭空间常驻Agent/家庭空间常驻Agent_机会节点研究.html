家庭空间常驻Agent · 产业价值链与机会节点研究（节点研究员 v1）

首次研究：2026-10-12 | 数据截止：2026-10-09（行情）/ 2026-10-12（公开信息） 定位：节点视角（价值链拆解、利润分配、机会节点），供企业研究员与财务估值研究员接力 纪律：所有数字标注来源与口径；缺数据明说；严格区分【已验证收入】与【订单/预期】 行情来源：数据采集脚本 quote/fin（新浪+东财，2026-10-09 收盘）；其余为公开报道，已在文中标来源

0. 一句话结论

家庭空间常驻Agent产业链上，当前唯一大规模"已验证收入"的环节是清洁/服务机器人整机（科沃斯、石头）与其上游激光雷达（禾赛、速腾）；执行器/灵巧手/减速器环节的全部收入体量对报表几乎可忽略（拓普执行器收入占比0.1%、兆威灵巧手收入未达单列门槛），但市值定价已透支3-10年的量产预期——价值链上"真利润在整机与感知，真泡沫在执行器概念"。家庭中枢平台与内容订阅环节当前无可投资的A股标的。

环节B：传感器（视觉/激光雷达第二曲线）

激光雷达是本链上最接近"真第二曲线"的环节：

  • 速腾聚创（2498.HK）【已验证收入】：2026H1激光雷达总销量71.92万台（+170%），其中机器人领域28.26万台，同比+510%；机器人业务贡献"近一半收入和大部分产品毛利润"（公司2026中报，证券时报07-09、公司业绩会）。2026H1激光雷达收入突破10亿元。注意口径：销量+170%但收入仅+30%（OFweek 08-28横评），单价快速下行——量真、价跌。
  • 禾赛（HSAI.US）【已验证收入】：2026H1出货110万台（机器人26.07万台），GAAP净利润0.89亿元（+234.9%），毛利率39.7%；激光雷达主业利润被投入SGI新业务（机器人动力模组、Kosmo），SGI二季度收入约4494万元仍亏损（OFweek横评）。
  • 奥比中光（688322）：3D视觉，PE-TTM 307.8x（10-09）——收入真实但几乎全是工业/支付视觉，家庭机器人收入无拆分，估值已按具身视觉定价。
  • 触觉传感器（柯力传感603662，PE 43.1x）：六维力传感器送样超50家客户（前瞻产业研究院2026-05汇编）——送样≠收入，无单列收入。

2. 价值分配：谁在圈钱、谁在积累真壁垒

真壁垒在积累的（证据导向）： 1. 石头/科沃斯：真利润、真渠道、真家庭数据流（3800万+家庭），具身智能是"用利润养期权"——科沃斯垂直一体化（电机/电池/传动自研+核心部件基地建设）是唯一在整机制造端自建执行器能力的玩家。 2. 速腾/禾赛：机器人激光雷达+510%销量是全链唯一"收入结构已翻转"的第二曲线；自研SPAD-SoC芯片是跨场景复用的技术代差。 3. 拓普/三花：平台化制造能力真实（电机自研+总成经验），但当前利润100%来自汽车——机器人是期权不是业绩，需盯"执行器收入占比"这一单一指标。

泡沫期在圈钱的信号（标时点2026）： - 兆威机电：H股募资14.85亿到账后购入11.7亿理财、同时讲"量产元年"叙事（21经济报道）——典型的"融资优先于投入"信号。 - 绿的谐波：350万台套产能规划 vs 当前年出货40万台（其中人形10万台），规划是现实的近10倍；PE 343x下扩产本质是市值融资叙事。 - 板块融资：2025年人形赛道融资270亿、企业超100家（虎嗅引UBS口径），瑞银预测2026全球出货仅3万台——资本投入强度与真实出货量差约两个量级。

整机 vs 核心零部件的议价权： - 当前（小批量阶段）零部件商表面强势（独供传闻、订单排产），实为伪议价权：单一大客户（特斯拉/头部整机）+ 技术路线未冻结（谐波 vs 行星 vs 丝杠未定）+ 整机厂自研垂直化（科沃斯、Figure自产执行器，Figure自产9000+执行器/10+SKU）。 - 高盛2026调研结论：三花、拓普等9家供应商均未获得大额订单；模组供应商"面临整机与整手两级客户挤压"（21经济报道引分析师）。 - 规量化后历史剧本（参考汽车零部件）大概率重演：年降压力、客户集中、议价权向整机/平台集中。灵巧手是零部件中议价权最脆弱的——技术路线最不收敛（直驱/连杆/腱绳三线并存），先发者无专利护城河证据。

4. 预期差盘点

4a. 人形概念股市场定价程度（10-09行情，数据脚本）

4b. 扫地机龙头第二曲线是否被低估——是，本报告最高置信的预期差

  • 科沃斯 PE 13.9x、石头 PE 16.8x（10-09）：市场按"成熟家电+价格战"定价， ignores：①科沃斯26H1净利+27%、海外51%占比、毛利率48.5%创优；②新品类（擦窗/割草/泳池）+88%增长；③全球扫地机渗透率仍低、 stones/科沃斯合计吃掉中国厂商出海红利；④两者是家庭空间常驻Agent唯一有"千万级家庭存量+高频在场数据"的上市公司——若Agent形态成立，扫地机是天然的先导硬件与数据入口。
  • 定价矛盾点：市场给"还没有收入的执行器"343x，给"每年赚25亿、净现比>1"的整机14x。错定价方向明确：不是人形预期被低估，是家庭在场性本身被低估。
  • 反方（红队预埋）：扫地机内销饱和、营销费用率奇高（科沃斯广告47.4亿/销售费用80%）、追觅崛起份额挤压（科沃斯全球份额降至13.7%第三）；"八界/毛团儿"具身收入未拆分，可能永远只是营销标签。预期差兑现需跟踪：具身产品单季收入首次单列披露。

5. 节点优先级排序（定性判断+证据+约束，无机械加权）

P1 · 清洁/服务机器人整机（科沃斯、石头）——唯一"利润当下为真+家庭在场性期权免费送"的组合。证据：PE 14-17x vs 26H1利润+27%/净现比>1。约束：内销饱和、追觅份额战、具身收入未单列（期权可能永远不兑现）。验证指标：具身收入单列、海外增速、份额。

P1 · 机器人激光雷达/感知（速腾、禾赛）——第二曲线已在报表上翻转（机器人占速腾收入近半、贡献大部分毛利）。约束：量增价跌（销量+170% vs 收入+30%）、港股/美股标的、禾赛SGI仍亏损。验证指标：机器人雷达ASP降幅收窄、触觉/关节模组2027年收入≈1亿目标（速腾指引）。

P2 · 拓普/三花类"主业厚+机器人期权"的执行器总成商——下有汽车业绩托底（PE 30-35x），上有期权。约束：高盛调研"9家均未获大额订单"；期权兑现的唯一可信指标是机器人收入单列>10%披露门槛，当前0.1%。

P3（回避级）· 纯概念执行器/灵巧手/空心杯（绿的343x、鸣志291x、兆威86x）——叙事方向没错、价格错了。若必须参与，等待PE与订单兑现的剪刀差收敛（绿的2028年4.3亿利润为卖方最乐观锚，即便如此现价仍透支）。兆威的"募资买理财"是治理信号。

当前无可投资标的（明说）： 1. 家庭中枢平台/入口生态——小米/华为不可投或不可拆，萤石为安防主业，卧安亏损+跌七成； 2. 内容与服务订阅——中国尚未发生第一笔规模化验证收入； 3. 家域端侧大模型——开源清零模型层利润，价值流向P1/P2的整机与芯片； 4. 端侧Agent SoC独立供应商——瑞芯微/乐鑫是泛AIoT敞口，无纯标的。

6. 分歧与待验证清单（留给监控/红队）

  1. 特斯拉2026年"5万台下线"是官方口径，但与"部署自用无销售渠道"并存——周产量与自用工时是唯一裁决指标，Q4若V3不亮相则时间表整体滑向2027H1。
  2. 绿的谐波人形出货10万台/年（调研口径）无公司正式确认；毛利率环比-4pct暗示价格战已开始。
  3. 扫地机"家庭在场性"预期差是本报告最高置信判断，但可证伪点明确：若26年报科沃斯/石头具身产品收入仍为零拆分且份额继续丢失，P1降级。
  4. 三花/拓普"独供"传闻全部来自卖方/媒体，无公司公告确认份额——供应链份额之争交由26Q3-Q4财报"机器人收入单列与否"裁决。
