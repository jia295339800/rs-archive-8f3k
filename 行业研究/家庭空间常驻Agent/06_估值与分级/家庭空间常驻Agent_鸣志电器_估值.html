重构结论：主业是"全球步进电机龙头"的真实底盘（份额、客户、37% 毛利率都是真的），但真实底盘的年利润只有 0.6-0.8 亿且连续两年下滑、ROE 2%。正常化利润不存在向上重构空间——23 年的 1.4 亿是周期与汇兑叠加的峰值而非中枢。

三、三情景估值卡片：裸估值 vs 现价，叙事溢价拆解

方法：主业微利但为正、盈利连续可测 → 正常化 PE 为主，PB-ROE 交叉校验（ROE 2.5% 的精密制造合理 PB 1.2-2.0x）；机器人期权按 SOP 纪律：无公告级收入单列 → 中性情景不计价，仅乐观情景给数量级期权（参照核心企业报告口径：已证实收入才给 1-3x PS）。

正常化 2026E 归母：26H1 已实现 0.372 亿；下半年为传统旺季（25H2 归母 0.341 亿）+ 收入 +15-19% 趋势，全年 0.75-0.90 亿（净利率 2.5-2.9%）。取中枢 0.8 亿。

叙事溢价拆解（与江淮同口径）： - 市值 199 亿 − 中性合理市值 50 亿 ≈ 145 亿机器人叙事溢价，占市值 72%（江淮：347 亿 / 70%）。 - 含义：现价买入者实际支付的是"乐观情景全值（约 120 亿）× 1.65"——市场不仅定价了乐观情景，还在其上再溢价 65%。乐观情景要求 2027 年机器人收入单列 ≥5 亿（相当于 26H1 全部收入的 1/3 来自机器人），而公司 A 级口径当前"占比极小"，中间隔着至少一个数量级。 - 若机器人叙事完全归零（C 级传闻全部证伪、送样永不转批量），股价理论锚在 35-55 亿，即 -72% 至 -82%。这是全队列已估值标的中最大的情景内下行。

固定项（SOP）： - 当前市值：198.97 亿 / PE-TTM 278.8x / PB 6.70x（2026-10-12 收盘，A） - 隐含预期：市场按"空心杯电机国产替代唯一龙头 + 特斯拉灵巧手定点在即"定价，隐含 2027-2028 年机器人收入 10 亿+、净利率 15%+ 的利润体量——与 A 级披露（收入占比极小）相差两个数量级。 - 与市场不同的核心判断：市场把"技术能做"等同于"订单会来"；空心杯赛道国内已有鼎智/捷昌/雷利多路产能，Maxon/Faulhaber 手握大批量工艺且开始本土化，鸣志的稀缺性溢价建立在大批量工艺领先的假设上，而该假设无任何 A/B 级订单证据。此外液冷第二叙事仅 0.36 亿收入，撑不起任何独立估值。 - 估值风险：①若某季度公告真实定点（A 级），中性情景需重估（上行风险对称存在）；②主业 26H1 +19% 若延续，0.9-1.0 亿利润可达，中性上修至 55-60 亿——不改变结论量级；③小市值+高波动，-72% 的理论锚不等于短期路径。 - 数据来源与基准日：行情 2026-10-12 收盘（数据采集脚本）；财报 23Q3-26H1 十二期（东财）；机器人敞口 26H1 业绩说明会实录（巨潮，A）。

固定三句话： 1. 最关键假设：鸣志能在人形机器人放量时拿下空心杯电机的大批量订单份额——当前这一假设的全部支撑是"技术参数接近国际水平"（C/B 级），无一单 A 级批量订单。 2. 最容易错的假设：把 2023 年 1.4 亿归母当作盈利中枢——实际是周期峰值，正常化中枢只有 0.8 亿上下，用 23 年利润算 PE 会把裸估值高估近一倍。 3. 下一步验证：26Q3 财报（2026-10 月末披露）看三点——机器人/空心杯收入是否首次单列、主业单季归母能否站上 0.2 亿、经营现金流能否修复。

四、分级：D

队列预期 C/D，定级 D（队列内继润建股份后第二个 D，江淮为 C 下行偏 D）。理由：敞口证据 C 级（连 B 级订单都没有）+ 叙事溢价占市值 72%（全队列最高）+ 悲观/中性情景下行 -72%~-82%（全队列最深）+ 主业自身盈利质量连续三年恶化（ROE 5%→2%）。

升降级触发条件： - ⬆ 升 C：A 级事件——机器人/空心杯收入在定期报告中首次单列且 ≥1 亿/年化，或公告级批量定点（具名客户+金额）；主业单季归母连续两季 ≥0.25 亿。 - ⬆ 升 C+：在升 C 基础上，机器人收入 ≥3 亿且毛利率 ≥35%（证明不是低价换量）。 - ⬇ 确认 D 且记负样本库：26Q3+26Q4 主业收入增速跌回个位数，或公司公告机器人业务无明显进展满两个报告期而市值仍 >150 亿（溢价无证据支撑的纯计时器）。
