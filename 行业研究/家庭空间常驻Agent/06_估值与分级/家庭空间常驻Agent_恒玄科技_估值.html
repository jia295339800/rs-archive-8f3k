与市场不同的核心判断：①市场把"毛利率抬升"读作安全垫，本报告认为它同时证明公司有能力转嫁成本——但转嫁的代价是订单流失（量缩），量价不能兼得，2026年量的底部尚未确认；②市场把AI眼镜当作第二增长曲线前置定价，本报告认为眼镜在2026年全行业出货量级仍小、恒玄无单列收入，溢价应打对折以上；③正面预期差：存储涨价对毛利率的压制被证伪（A級），26H2毛利率有望站稳42%+，这是市场尚未充分计价的利好。

4. 方法说明
