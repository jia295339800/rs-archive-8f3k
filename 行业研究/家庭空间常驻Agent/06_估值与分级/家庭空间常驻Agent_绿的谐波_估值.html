2.2 产能利用率：U型但远未满产

A级轨迹（证券时报引募集说明书/问询回复）：2021年107%→2022年84%→2023年51.6%→2024年42.7%→2025年67.8%（产量43.37万台+72%）。2025年回升是真实需求（新签订单+61%），但：①67.8%仍低于2021年水平；②IPO募投50万台项目达产后总产能59万台——现有产能尚有余量；③14亿定增募投（新增100万台+执行器20万套）投资进度仅8.39%、延期两年至2028年底，公司自述原因"前期产能利用率较低、聚焦消化IPO产能"。产能叙事（"订单排到明年、扩产百万台"）与公司自己的资本开支行为直接矛盾——公司用真金白银投票表达了对短期需求的谨慎。

2.3 治理与红旗（影响估值折价）

  1. 募资-理财循环：定增14.02亿（2024-12到位）一年半仅投1.18亿，10.15亿买理财（+457%），金融资产+现金占总资产58.3%——闲置募资套利，2024年8月曾因现金管理违规被出具警示函（A级）。
  2. 再融资叠加：定增未完工即启动H股融资（A级公告）——激进融资样本。
  3. 年报内部张力：行星滚柱丝杠正文称"规模化量产"、在研项目表标"小试"（写春秋A级引述）——新业务披露口径需打折。
  4. 正面项：研发全费用化（资本化为零）、前五大客户分散、以销定产、自研磨床（关联方采购，注意关联交易属性）——制造业底子真实。

2.4 正常化利润（估值基准）

  • 2025归母1.24亿 − 金融资产损益0.53亿 = 经营性≈0.72亿。
  • 2026E：收入7.0-7.5亿（H1 +38.6%年化、订单支撑，H2高基数下增速回落至25-30%），毛利率续降至30-31%，费用率刚性 → 经营性归母1.0-1.3亿；含金融收益（0.5-0.7亿）账面约1.6-1.9亿。
  • 估值只用经营性口径：金融资产损益按净现金单独计价，不入PE倍数（严守经营性vs金融性纪律）。

3. 三情景估值卡片（正常化PE + 期权数量级）

方法说明：绿的商业模式=高壁垒精密零部件成长股，适用正常化PE；DCF不适用（现金流全被理财收益和产能节奏扭曲，贴现率无锚）；人形机器人贡献只做数量级期权计价（红队§4.2教训：不呈现虚假精确，只说"百亿级以内/几十亿级"）。金融资产（净现金约20亿量级：金融+货币23.8亿 - 无有息负债约）单独加回。

4. 方法按商业模式选择的说明

  • 正常化PE（经营性口径）+ 净现金单列：适用，因利润含42%金融损益、必须拆分；净现金给20亿（保守，理财可回收）。
  • 不用DCF：资本开支节奏被募投延期人为压平、金融损益污染FCF，预测无锚。
  • 人形期权数量级计价：按红队§4.2裁定，不再呈现"0-60亿"式虚假精确，中性只表述为"几十亿级以内"、乐观"百亿级以内"；与鸣志（主业微利+灵巧手路线未收敛，期权应趋零）、奥比（机器人收入高增A/B级，期权可有几十亿级）保持同一口径。
