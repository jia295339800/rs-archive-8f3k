1. 科沃斯（603486）｜B+｜整机+家庭Agent期权白送

1.1 财务质量：正常化利润重构

  • 账面：2025营收190.40亿(+15.1%)、归母17.58亿(+118.1%)、扣非16.20亿(+126.1%)（2025年报，经审计）；2026H1营收103.41亿(+19.2%)、归母12.48亿(+27.4%)，毛利率48.5%（26H1，东财）。
  • 非经常项重构（关键）：2025归母含投资公允价值变动收益（对外投资企业公允价值增长，年报明确列为净利大增主因之一；2026H1含参投关节/灵巧手企业公允价值收益约2.24亿，候选企业清单B级口径）。科沃斯本身有产业投资组合（睿尔曼等），该项收益质量低、不可持续。2026Q1扣非3.97亿同比明显增长（新华网04-27），但2026H1扣非同比-6.37%（候选清单口径）→ 扣非增速已趋平。
  • 费用结构：2025销售费用59.38亿（费用率31.2%）vs 研发9.81亿（5.2%），6:1——利润对营销投放极其敏感，价格战重启时费用杠杆反噬。2026H1财务费用-1.64亿（汇兑收益），2026H1经营现金流仅2.06亿（同比-85.8%，半导体备货+国补回款错位，Q1经营现金流1.91亿同比-78.6%，公司Q1公告）。
  • 正常化利润：剔除公允价值变动/投资收益（2025约2-3亿税后口径估计，缺精确披露，标注推测）、剔汇兑损益后：2025正常化归母≈15-16亿；2026E按收入+12-15%、净利率8.5-9.5%（2025年11.3%含非经常项偏高）→ 正常化2026E≈20-22亿。

固定三句话：科沃斯13.9x买的不是机器人公司，是一台年产25亿现金流、被价格战叙事错误定价的家庭入口机器；正常化利润20-22亿对应中性290-330亿，当前价格几乎无安全边际也无泡沫，属"合理偏便宜"；升级条件是具身收入首次单列，降级条件是扣非连续两季负增长。

升降级触发：⬆ 2026年报八界/具身产品收入单列>3亿，或扣非增速回正+份额止跌；⬇ 全球份额跌破12%或Q3-Q4扣非同比双位数下滑。

2. 石头科技（688169）｜B+｜基本面最扎实的整机

2.1 财务质量：正常化利润重构

  • 账面：2025营收186.95亿(+56.5%)、归母13.63亿(-31.0%)、扣非10.92亿(-32.6%)；OCF 7.74亿(-55.4%)（2025年报，经审计）。2026H1营收100.84亿(+27.6%)、归母9.86亿(+45.6%)、扣非8.03亿(+60.7%)、OCF 3.98亿（上年同期-8.23亿，转正）（26H1公告，华尔街见闻引）。
  • 利润下滑的性质重构：2025年"增收不增利"是主动战略投入——①全价格段+新品类（洗地/洗烘/割草）市场推广；②自营渠道扩张+大促备货（存货+62%，候选清单）；③研发投入14.20亿(+46.1%，占营收7.6%)；④海外运费与渠道投放挤压（境外收入104.42亿占56%，海运成本+海外仓+亚马逊广告费是石头利润率低于科沃斯的主因——石头毛利率42.3% vs 科沃斯48.5%，26H1东财）。这不是恶化，是把利润换成了全球份额：2025全球扫地机份额27%第一（IDC）。
  • 正常化利润：2025的13.63亿含约2.7亿非经常项与主动投入；若投放效率回归（费用率-1.5pct），正常化2025≈15-16亿。2026E：股权激励目标收入+15%（≈215亿），净利率8.5-9%→ 归母17-19亿；扣非口径16-17亿。

升降级触发：⬆ 2026全年扣非>18亿或G-Rover形成独立品类收入；⬇ 存货周转天数继续恶化/北美关税升级/份额丢失。

3. 拓普集团（601689）｜C+｜厚主业+尚未定价成立的机器人期权

3.1 财务质量：乘用车主业与机器人期权分开

  • 账面：2025营收295.81亿(+11.2%)、归母27.79亿(-7.4%)（2025年报，经审计）；2026H1营收142.0亿(+9.7%)、归母10.23亿(-21.0%)（东财/候选清单）。毛利率19.4%（2025）→ 18.8%（26H1），净利率9.4%→7.2%。
  • 主业周期：汽车价格战年降传导，Q4'25曾+6%修复但26H1再度-21%——主业处于下行周期中段。单车配套价值3万元、8大产品线的平台属性仍在（Tier0.5），但盈利被客户挤压。应收账款/归母净利263%（证券之星03-25），占款模式是隐形质量折扣。
  • 机器人执行器（严格分开）：2026H1收入1404.77万元（+83.4%），占总营收0.10%，毛利率27%（26中报）；累计机器人订单"突破50亿"为公司口径（B级，未全部转收入）；"Tesla审厂+5000台订单"为C级（公司回应"暂未接到审厂通知"）。50亿宁波机器人电驱基地首期基本建成（B级公告）。
  • 正常化利润：2026E主业归母26-28亿（H2年化略好于H1，但价格战延续），正常化取28-30亿（含机器人执行器贡献<1亿）。

6. 核心预期差检验（任务第4问）

6.1 "扫地机双龙头PE14-17x被低估"是否成立？

结论：方向成立、幅度有限——是"合理偏便宜"，不是深度低估。 - 三情景反推市场定价隐含的悲观假设： - 科沃斯283亿 = 正常化16亿×约18x？不对——用13.9x TTM反推：市场实际定价≈永续零增长的成熟家电（隐含2026E利润21亿×13.5x），即隐含假设"海外增长抵消内销下滑、利润不再增长、Agent期权价值=0"。 - 石头281亿 = 2026E 17亿×16.5x，隐含"2025年利润下滑是起点、修复不可持续"——比科沃斯更悲观，连26H1扣非+61%的已发生事实都没有定价。 - 但为什么不判"深度低估"？因为悲观情景确实是开放的：科沃斯悲观176亿（-38%）、石头悲观195亿（-31%）——价格战重启+费用反噬时下行是真实的。中性vs现价的差只有0%~+28%，不是"翻倍级"预期差。 - 被低估的准确表述：市场定价了"家电"，没有定价"家庭在场性"——两者合计3800万+家庭存量、高频数据入口、自研执行器能力，是A股唯二。期权价值我们仅给0-20亿（占总市值<7%），因为：①具身收入至今为零且未单列；②科沃斯董事长自己说"行业巨大泡沫、乐观3年悲观5年"（B级，2026-09）；③家庭Agent商业化时间表（产业趋势研究）中性为2028-2029年。期权免费是加分项，但不能作为买入的主要理由。 - 判定：P1结论维持，但从"最高置信预期差"降格为"结构合理、等待右侧"——触发升级的验证指标不变：具身收入单列披露。

7. 泡沫定价程度：绿的谐波 / 鸣志电器 / 奥比中光（不估值，仅反推隐含出货量）

三家的共同点：当前市值无法用任何现实利润/收入解释，唯一办法是反推"市场隐含的2029-2030年世界"。

绿的谐波（688017，市值484亿、PE 343x、PB 13.4x，10-09） - 2025归母1.24亿撑484亿。假设2030年兑现：谐波减速器人形单台用量14-20个、单价值1500-2500元 → 单台减速器价值约2-4万元；若给予2030年30x PE、届时净利率20%，则需2030年归母16亿 → 对应收入80亿 → 隐含2030年人形出货 20-40万台/年（仅绿的份额50-70%口径），是全球2026年出货（3-5万台）的5-10倍，且要求每年翻倍以上连续增长。若出货量仅达德银乐观2028年30万台的1/3，绿的当前价高估3倍以上。

鸣志电器（603728，市值208亿、PE 291x） - 2025归母约0.7亿量级（26H1仅0.37亿）。同样按2030年30x/20%净利率反推：需2030年归母≈7亿、收入35亿——其中空心杯电机需在人形灵巧手上拿到每台价值3000-5000元×年出货30-60万台的份额，且要在直驱/腱绳路线之争中胜出。隐含假设是"灵巧手路线收敛到空心杯+鸣志独占"——双重未验证假设叠加，是三者中隐含假设链条最长、泡沫程度最高的（其主业步进电机为成熟微利业务，无法支撑291x中的任何部分）。

奥比中光（688322，市值337亿、PE 308x） - 2025归母1.28亿（首次盈利）。反推需2030年归母11亿、收入45亿（30%净利率）——2025年收入9.41亿，要求5年5倍。3D视觉单机器人价值量800-2000元×年出货50-80万台才能支撑；但其收入的现实基本盘是工业/支付视觉而非家庭机器人，机器人收入高增但无拆分（A/B级）。泡沫程度略低于前两者（有平台成长先例可类比，如舜宇光学早期），但308x仍把"机器人之眼标准品"的2030年胜利提前定价。

泡沫排序：鸣志（双重假设+主业微利）> 绿的（单一大客户+产能叙事10倍于现实）> 奥比（增长结构最好但仍透支）。 三者10-12月自高点已回调20-40%（绿的市值曾770亿→484亿），泡沫部分出清、远未出尽；任何"PE回落到100x以内"+"机器人收入单列"双条件出现前，按叙事定价处理，不参与估值分级。
