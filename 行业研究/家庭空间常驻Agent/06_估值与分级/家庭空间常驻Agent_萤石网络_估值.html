0. 结论速览

分级：B+（中性偏正，队列内估值最优档之一）。214.6亿市值 ≈ 31.8x TTM / 29-30x 2026E（本报告2026E归母7.0-7.4亿），处于上市以来PE区间（33-69x，平均46x）下沿以下。基线业务（全球消费摄像头份额第一13.9% + 高毛利云平台占比首破20% + 海外占43%）真实、盈利质量在改善（利润增速持续3倍于收入增速）——而市场按"卖摄像头的"给制造业估值，云平台的SaaS溢价（毛利率71%+、付费率6%、B端开发者服务+26%）未充分定价（红队R2修正：30x整体倍数或已隐含部分云价值，非"≈0"；中性区间已按云65x+硬件22x计入重估空间，与此自洽）。家庭中枢叙事（AI Core X家庭本地大模型主机 + 蓝海大模型L4具身智能体 + 场景化AI服务）是全场候选中形态最完整的，但收入贡献极小且智能服务机器人收入在收缩（26H1 -29.4%），只能做免费期权。风险同样明确：营收增速已降到个位数（26H1 +6.35%）、经营现金流转负（-0.6亿，主动备货存货+80.6%）、海康系关联与独立性是永久折价项。

机器人收入未单列的披露缺口——处理方式（任务核心问题）： 1. 事实澄清：萤石并非完全不做品类拆分——中报/年报"分产品"披露智能家居摄像机、智能入户、机器人、配件的同比增速，但机器人绝对额只在部分报告期出现（如2025H1披露0.6亿），2025年报及2026中报的公开摘要层未给绝对额。处理：以最近一次披露的绝对额为基数、用后续披露的增速倒推（26H1 ≈ 0.4亿，占1.4%），并标注为推算值（B级）。 2. 为何影响估值：机器人收入仅~1.4%且负增长，意味着"中枢+机器人"叙事的收入兑现层几乎为零——家庭中枢故事当前的可验证支柱是云平台（SaaS），不是机器人本体。估值中机器人/中枢按期权计价，不给分部价值。 3. 补缺口路径：26Q3/2026年报若把AI Core X或机器人收入单列并给量级（管理层口径"很少"→数字），缺口闭合，期权转实值候选（见§5触发）。

敞口小结：萤石的家庭中枢叙事=云（A，已兑现）+ 摄像头/入户入口（A，硬件基本盘）+ 中枢主机/机器人（B，零到极小收入）。三要素形态全场最齐，但兑现层级清晰：值钱的是云，讲故事的是中枢。

  • SaaS属性检验（任务要求）：通过。①云平台收入占主营首破20%且占比逐期上行（2023H1 16.7%→2026H1 21.3%）；②云毛利率71%+，与硬件39-47%形成双结构；③递延证据链完整——合同负债中"云增值及开放平台服务"持续增长（26H1一年以上未履约部分继续增加，A级），符合订阅制先收后确认特征；④付费率6%不高但ARPU提升路径（AI增值订阅）已开始兑现。结论：云平台可按SaaS分部单独估值，非纯硬件公司。
  • 盈利质量警示：①26H1经营现金流-0.6亿（-118%），存货较年初+80.6%至13.7亿——公司口径为应对存储供需变化主动备货（存储在硬件成本占15-20%，也可视为提前锁料的对冲），但现金流转负+存货激增组合必须连续跟踪，若26Q3存货不随收入消化即转为红旗；②财务费用+149%（汇兑损失，人民币升值对43%海外收入的压力是双向剑）；③应收账款/利润209%（证券之星体检）——海康系与运营商渠道的历史特征，需关注。

2.2 治理与红旗：海康系关联与独立性（任务点名项）

  1. 股权与关联：海康威视直接+间接控股约60%（中电海康/中国电科体系），公司需定期发布《关于中国电子科技财务有限公司的风险持续评估报告》（2026-07公告在列）——存在财务公司存款安排。历史上海康曾为前三大客户（2021H1占10.66%）。估值含义：独立性折价是永久性的（治理折价约1成，参照市场对分拆标的惯例），但换个角度：渠道/供应链/工程师红利来自海康的输入也是真实的，不能只算成本不算收益。
  2. 正面：上市以来累计分红10.41亿（融资32.37亿，分红融资比0.32）；2025年度权益分派已实施；账面货币资金40.6亿、几乎无有息负债，安全垫厚。2026年"提质增效重回报"专项行动半年度评估已披露。
  3. 红旗清单：研发人员数-2.76%（26H1，1373人）——AI叙事下研发人数收缩需在26Q3确认是否为结构性调整；机器人品类连续收缩+公司未解释战略定位变化。

2.3 正常化利润（估值基准）

  • 26H1归母4.10亿。季节性：2025年H1占全年53.3% → 2026E = 4.10/0.533 ≈ 7.7亿；但26H1利润高增部分来自毛利率跳升与低毛利业务收缩的一次性结构效应，且汇兑/研发扰动双向，取保守带7.0-7.4亿（对应全年利润增速+24%~+31%），卖方一致预期7.1亿落在带内。
  • 分部利润拆分（估值用，参照华泰SOTP框架并下修）：云平台2026E收入~7.3亿（+15%），SaaS净利率45%→约3.2亿；硬件（摄像机+入户+机器人+配件+其他）约3.8-4.2亿。
