数据基准日：2026-10-12｜财报覆盖：2023FY–2026H1｜币种：人民币｜主要估值年：2026E｜证据与数据限制：核心财务取自2025年报与2026中报（上交所披露，A级）及东财RPT_LICO_FN_CPD/RPT_VALUEANALYSIS_DET（A级，与定期报告核对一致）、新浪行情同日交叉；分产品绝对额仅部分报告期披露，机器人收入以最近绝对额×增速倒推（推算值，B级）；三档情景按2026E/2027E正常化年化利润测算，2026Q3季报尚未披露。

0. 结论与估值卡片

一句话结论：萤石的利润来源是"全球消费摄像头份额第一的硬件基本盘+占比首破20%、毛利率71%的云平台订阅"，当前最主要的争议是——云的SaaS属性值多少倍、家庭中枢（AI Core X主机+蓝海大模型+机器人）期权值多少钱；当前31.9x TTM（约30x 2026E）更接近中性档下沿，云SaaS溢价未充分定价，中枢期权接近免费。

1. 这家公司到底做什么？怎么赚钱？

一个具体场景：一个三口之家装了萤石摄像头看老人孩子，每月付十几元开通云存储回看；门锁用萤石智能锁（3000元+价位段线上第一），全屋设备接入萤石云开放平台。硬件是一次性收入（毛利率39-47%），云订阅是先收后确认的经常性收入（毛利率71.05%，26H1收入6.4亿、占主营21.3%，A级）。公司赚钱的方程：硬件走"份额×单价×制造毛利"，云走"设备接入量3.6亿台×付费转化6%×ARPU"，云的边际成本极低、续费复用同一套基础设施。

3. 核心利润池：真正决定估值的3–5个变量

3.1 云平台的SaaS成色——估值的第一变量

2025年云服务收入12.05亿（+14.51%），C端增值5.29亿+B端开发者6.75亿（+26.03%）；26H1再+15.9%。SaaS属性检验通过：①收入占比16.7%（2023H1）→21.3%（26H1）逐期上行；②毛利率71%与硬件39-47%双结构；③合同负债中"云增值及开放平台服务"持续增长、一年以上未履约部分继续增加（A级，订阅先收后确认）；④付费率6%+AI增值ARPU上行路径已开始兑现。云按2026E利润3.2亿（净利率45%，参照华泰SOTP框架下修，C级锚仅作交叉）×55-85x区间。

3.2 硬件基本盘的份额与结构——利润的压舱石

摄像机份额13.9%全球第一但增速+2.0%见顶；智能入户+28.2%量价齐升、行业-18.1%背景下的份额逻辑是第二成长曲线。硬件正常化利润约3.8-4.2亿（2026E，分部拆分推导），给18-28x。

3.3 家庭中枢与机器人——免费期权

AI Core X主机（64T算力、本地蓝海大模型+Home Vita智能体）是候选清单中最贴近"家庭空间常驻Agent"形态的产品（B级，发布会官宣、海外首发），无收入单列、出货量均价均未披露；机器人收入约0.4亿（倒推，B级）且-29.4%收缩（A级负面）。按纪律：B级证据不入中性情景利润，期权单列、中性不计价。

敏感性计算（可复算）：以2026E收入63亿为基数，综合毛利率每变动1pct→毛利变动0.63亿（税前）→按实际税率约15%、无少数股东，影响归母约0.54亿元，约相当于中性档利润的7.4%、对应市值约±16亿（±6%）。另一敏感性：云收入增速从+15%降到+8%，2026E云利润约减少0.3亿，按65x即影响市值约20亿（±7%）——云增速是比硬件更贵的变量。

正常化年化：2025年H1利润占全年53.3%，机械年化=4.10/0.533≈7.7亿；但26H1高增含毛利率跳升的结构性效应与汇兑扰动，取保守带7.0-7.4亿（卖方一致7.1亿带内交叉，C级仅参照）。扣非≠经济利润：本例中扣非与正常化几乎一致，最脆弱环节是毛利率——存储涨价若传导失败，50.3%回落3pct即回到悲观档。

5. 现金流、再投资与资产负债表

  • OCF/归母净现比：2025全年每股OCF 1.42元（OCF≈11.2亿、净现比≈2.0）→26H1每股-0.076元（OCF -0.6亿）。恶化主因主动备货：存货13.7亿（较年初+80.6%）。应收账款/利润209%（证券之星体检口径，B级）为海康系与运营商渠道历史特征，需跟踪。
  • Capex与FCF：轻制造结构，Capex温和；2025年FCF为正、26H1为负（备货占用）。分红融资比0.32，上市以来累计分红10.41亿。
  • 杠杆与稀释：货币资金40.6亿、几乎无有息负债，无转债无增发摊薄在途。
  • ROIC：2025年ROE 10.1%；云业务增量ROIC约35%+（毛利率71%、边际成本低，估算口径），云占比提升本身在抬高整体增量ROIC——这是"云SaaS溢价未定价"判断的财务实质。当前唯一侵蚀点是备货占用的增量资本，26Q3存货环比为检验读数。

关键判断：利润现金含量历史上优（2023/2025净现比>1.5），26H1转负是备货节奏而非盈利质量恶化——但必须连续验证；未来两年估值支撑来自云订阅的经常性收入与结构升级，而非现金流扩张故事。

6. 三情景估值：利润和倍数分别从哪里来？

6.1 悲观：需求二次走弱+备货变滞销

2026E收入约60亿（+2%）、毛利率回落至46%、归母6.8亿。倍数：SaaS溢价归零、按消费硬件+弱增长给整体PE 24-26.5x（该区间由"增速<5%、ROE 9%、无期权"独立推导，与现价无关）。目标市值165-180亿，每股20.9-22.9元，较现价-16%~-21%。

6.2 中性：以结构升级对冲需求平淡（最符合现有证据）

2026E收入约63亿、毛利率48%-50%、归母7.2亿。倍数：分部法云3.2亿×65x+硬件3.9亿×22x≈294亿（云55-85x带中段、硬件带内，SaaS溢价部分定价），整体法交叉校验7.2亿×34-38x=245-274亿，两法取带245-275亿，每股31.1-34.9元，较现价+14%~+28%。机器人/中枢期权中性不计价（B级证据纪律）。

6.3 乐观：AI增值放量+机器人止跌单列

2027E归母8.7亿（AI Core X贡献收入、AI订阅ARPU上行、机器人品类止跌并单列）。倍数：整体PE 37-44x（低于历史带33-69x中位，因收入增速仍个位数；上限需AI收入单列的A级事件）。目标市值320-380亿，每股40.6-48.3元，较现价+49%~+77%。

三档单调：6.8<7.2<8.7亿；中枢172/260/350亿，档间差≥35%（>15%要求）。

交叉验证：①历史PE带33-69x（均值46x），现价31.9x处下沿以下、38%分位以下；②FCF yield：中性260亿对应正常化FCF约7-8亿，yield约3%，对订阅型混合结构不苛刻；③分部法（294亿）与整体法（245-274亿）差约8%，已按孰低取带——云溢价取保守侧。

7. 是否需要压力测试或状态迁移估值？

压力情景：未单设。悲观档已包含毛利率-3pct+备货变滞销+机器人继续收缩；若26Q3存货环比再升且收入增速<5%，即为悲观档成为基准的触发，不需另编更深的档。

状态迁移情景：有实质可能——"摄像头硬件公司→家庭空间常驻Agent中枢平台"（AI Core X+蓝海大模型+云）。但尚未达到单列条件：中枢主机无收入单列、机器人收入在收缩，目标年份利润与迁移概率均无法可观测估计。按skill要求仅记录：若2026年报/2027年中报出现"AI/机器人收入单列且年化≥2亿"的A级披露，届时按折现迁移情景重估，不与当前三档并列加总。

8. 当前价格已经隐含什么？哪里存在预期差？

市值214.6亿÷三档利润：隐含PE(TTM 31.9x)低于中性档整体法34-38x下限；隐含PE(2026E中性7.2亿)=29.8x——当前价格没有完全定价中性情景。市场相信什么：摄像机现金牛+入户成长+利润率改善可持续。市场仍在质疑什么：①收入增速个位数是否配得上30x+；②26H1现金流转负与存货激增；③海康系独立性。我们与市场最大的分歧在云的定价方式：市场按"整体一家硬件公司"给倍数，我们按SaaS分部拆——仅云分部被重认知（55x）就有约20-30%重估空间；而家庭中枢期权在现价中接近免费，方向性利好无成本。悲观向下空间：172亿中枢对应约-20%，是全队列最浅的下行之一。

10. ABCD分级和升降级条件

当前分级：B+。 依据：基线真实（份额第一A级、云SaaS检验通过A级、利润增速35%）、估值处历史下沿以下且隐含低于中性档、悲观下行浅（约-20%）；不给A的原因：收入增速个位数、现金流暂时为负、中枢/机器人收入未兑现也未单列、海康系独立性永久折价。

升级条件：①机器人/AI Core X收入单列且年化≥2亿（披露缺口闭合，单一最强触发）→升至A-；②26Q3存货环比回落+OCF转正+云增速回20%+→维持B+并上修中性；③云分部被卖方普遍SOTP化且现价PE≤28x（事件性错杀）→A-。 降级条件：①26Q3存货续升且收入<5%→降至B；②2026全年归母<6.5亿或智能入户增速跌破15%→降至B-；③海康系关联安排负面变化→降至B-。 限制条件：机器人收入绝对额为倒推值（B级），一切涉及该数字的结论需26年报单列后复核。

11. 最终判断、主要证据与局限

悲观172亿｜中性260亿｜乐观350亿（中枢）。 中性最可能成立的证据：26H1毛利率50.3%与扣非+34.4%同步出现、云占比首破20%且合同负债续增、智能入户在行业-18%时+28%——结构、质量、份额三个变量同时向好。

长期价值来自两个真实结构：一是云平台从"摄像头附属"长成独立SaaS利润池（B端开发者+26%是生态证据），二是入户品类在存量行业中抢出量价齐升。目前价格最容易错的地方：市场用"卖摄像头的"整体倍数一家定价，把71%毛利率的订阅收入与44%毛利率的硬件收入混在一个PE里——若26Q3存货与毛利率双验证通过，云分部的重认知是第一段重估；家庭Agent故事若在2026年报兑现单列，则是第二段免费期权行权。反过来的错误是：把"形态最完整的中枢叙事"提前计入——机器人收入正在收缩（A级），故事未兑现前一分钱都不该入中性。
