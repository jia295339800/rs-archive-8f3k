二、重点核查：机器人收入占比（按任务要求逐项）

2.1 科沃斯（603486）——机器人收入占比

  • A级事实：2026H1营收103.41亿(+19.18%)，归母12.48亿(+27.40%)；其中科沃斯品牌服务机器人收入60.94亿(+26.8%)，添可品牌(洗地机等智能电器)40.51亿(+10.66%)，双品牌合计>98%营收。即"机器人"口径收入约59%，但其中几乎全部是扫地机/擦窗/割草等"工具级"清洁机器人，不是家庭常驻Agent。
  • 家庭常驻Agent相关："八界"管家机器人（轮式+六自由度机械臂，2026年发布并开源）仍处研发展示阶段，首批面向科研机构/先锋人群，尚未大众销售 → 收入贡献≈0（B级：公司发布+董事长专访，2026-09）。"毛团儿"AI宠物机器人(3999元)2026年3月开售，媒体口径销量极低（C级）。
  • 2025全年：营收190.40亿，归母17.58亿(+118%)；注意利润含投资公允价值变动（非经常性），2026H1扣非同比-6.37%。
  • 董事长钱东奇2026-09专访（B级官方表态）："整个机器人行业存在巨大泡沫"、路线是"类人形、能干活"的多任务家用机器人而非人形；投资关节、灵巧手企业做产业链牵引；具身智能进入家庭"乐观3年悲观5年"。
  • 财务质量注意：2025年销售费用59.4亿 vs 研发9.8亿（6:1）；2026H1经营现金流2.06亿（同比-85.8%，含半导体备货因素）。

2.2 石头科技（688169）

  • A级：2025年扫地机器人收入151亿、占营收81%；2026H1营收100.84亿(+27.6%)、归母9.86亿(+45.6%)，境外占60%+。全球智能扫地机份额第一（IDC，2026H1欧洲亚马逊市占45%、北美33%，媒体引述口径）。
  • 家庭Agent演进路径（B级，产品发布）：2025年G30 Space五轴仿生机械臂（地面→低空取物）；CES 2026发布G-Rover轮足式可爬楼扫地机——公司路线是"扫地机为躯干的具身智能"，不做人形。
  • 无独立"具身机器人"收入单列；其机器人收入=扫地机+洗地机+割草机，占比≈100%主营。

2.3 萤石网络（688475）

  • A级：2026H1营收30.07亿、归母4.10亿；2025全年营收59.0亿、归母5.67亿。主业是智能家居摄像机+智能入户（"2+5+N"体系），机器人品类（RK系列家庭助理机器人、清洁机器人）未在披露中单列收入 → 具体占比数据缺失，此处如实标注"缺"。品类收入拆分需查年报"分产品"明细（后续任务补）。
  • 常驻Agent相关（B级）：蓝海大模型2.0（L0–L4五级，L4=具身智能体）；2026 AWE发布"萤石星辰世界模型"+Stella蒸汽洗地机；EZVIZ AI Core X家庭本地大模型主机（存储+计算+控制一体的家庭中枢，海外首发）——这是清单内最贴近"家庭空间常驻Agent"中枢形态的产品叙事，但收入贡献极小。
  • 判断：敞口真实存在（既有机器人产品线+家庭中枢硬件+自研模型），但财务证实程度低，介于A（既有品类）与B/C（Agent属性）之间。

2.5 执行器公司已证实（A级）收入敞口

  • 拓普集团：2025年报"机器人执行器"收入1,359万元（占总营收0.05%）；2026H1为1,405万(+83.4%)，毛利率27%。→ 有收入但几乎为零，当前估值弹性来自预期而非业绩。
  • 绿的谐波：2025年"工业及具身智能机器人零部件"收入4.23亿、占74.04% → 全场机器人敞口最高、最纯粹。
  • 双环传动：2025年减速器及其他收入7.95亿（占8.73%）、智能执行机构7.98亿（占8.75%）；RV减速器子公司环动科技（分拆上市推进中）。
  • 鸣志电器：2025年控制电机及驱动系统22.93亿，但无公告确认的具身机器人批量客户（36氪产业链核查结论：不能把传闻客户写成实际订单）→ 敞口证据级C。
  • 兆威机电：灵巧手微型传动为官网/产品发布级（B级），无单列收入。
  • 三花智控：机器人收入未在已披露分部中单独证实（媒体称8.2亿，C级）。

三、业务理解卡片（每家一张）

卡片 1｜科沃斯 603486

  • 业务：扫地机/擦窗/割草/泳池等家庭清洁机器人（科沃斯品牌）+洗地机（添可）。2026H1海外占49%并首超半程（Q2达51%）。
  • 家庭Agent敞口：最高优先级整机标的。"工具→管家→伴侣"三阶段路线，八界（轮式+机械臂+双RK3588+OpenClaw/Hermes智能体，全平台开源）是当前A股最接近"家庭空间常驻Agent"的已发布实体产品——但未商业化。参投关节/灵巧手产业链（睿尔曼等，2026H1贡献公允价值收益约2.24亿）。
  • 证据分级：机器人主业A；八界B；毛团儿销量C；"不做人形、警惕泡沫"战略表态B。
  • 三分法：产业核心=高（家庭场景数据与渠道稀缺）；价值创造=中高（主业真金白银，但Agent新业务收入≈0、扣非利润2026H1转负增长）；投资吸引力=中（PE 13.9x便宜，但便宜是"家电估值"，Agent期权未被定价；汇兑、销售费用、存储涨价三重压力）。

卡片 2｜石头科技 688169

  • 业务：全球扫地机龙头（份额27%第一），洗地/割草扩品，海外60%+。
  • 家庭Agent敞口：以扫地机为躯干的能力扩展（机械臂→轮足爬楼），渐进式具身智能；不做人形。研发费用2025前三季10.28亿(+60.6%)。
  • 证据分级：机器人收入A（占81%）；G-Rover/机械臂产品B；Agent化收入C。
  • 三分法：产业核心=高；价值创造=高（增收又增利，经营现金流转正）；投资吸引力=中高（PE 16.8x + 真实盈利 + 全球份额，清单内基本面最扎实之一；存货+62%需跟踪）。

卡片 3｜萤石网络 688475

  • 业务：智能家居摄像机/入户/机器人/控制/穿戴五大硬件 + 萤石云平台 + 蓝海大模型。中国电科系（中电海康）。
  • 家庭Agent敞口：清单内"中枢+模型+本体"三要素最齐的标的（AI Core X中枢、蓝海大模型L4具身智能体、RK家庭助理机器人、Stella清洁机），但各线均早期。

四、三分法总评：产业核心 ≠ 价值创造 ≠ 投资吸引力

产业核心（在家庭常驻Agent产业链中的位置稀缺性）排序： 绿的谐波 ≈ 奥比中光 > 拓普/三花（执行器总成）> 科沃斯/石头/萤石（家庭入口+场景数据）> 双环 > 兆威/鸣志/乐鑫 > 恒玄/全志 > 极米。

价值创造（当下真实收入与利润）排序： 三花 ≈ 石头 ≈ 双环 ≈ 乐鑫 > 科沃斯 > 萤石 ≈ 拓普 > 全志/恒玄 > 绿的 ≈ 兆威 > 奥比 > 鸣志 > 极米。 （注意区分：科沃斯/石头的"价值创造"来自清洁机器人主业，不来自家庭Agent；真正由"常驻Agent"直接创造的收入，目前全场≈0。）

投资吸引力（证据/估值匹配度，非推荐）： - 证据充分+估值合理：石头科技、双环传动、乐鑫科技； - 证据充分+估值极贵：绿的谐波、奥比中光（产业地位真实，价格已透支）； - 证据不足+估值已含预期：三花智控、鸣志电器、全志科技（预期与证据错配重灾区）； - 主业便宜+Agent期权免费送：科沃斯（13.9x PE买主业，八界期权未定价，但需接受扣非利润下行与新品类商业化遥远）； - 中枢叙事最完整、收入最薄：萤石网络。

纪律提示：本清单中任何"Tesla订单""XX亿框架单""独家供货"均为C级信息，若后续出现公司公告（如定点公告、大额合同公告、年报分产品单列机器人收入），应即时升级为B/A级并重估。
