明泰铝业（601677.SH）红队R1审查：独立复采与逻辑挑战

审查对象：06_估值与分级/明泰铝业_明泰铝业_估值.md + 明泰铝业_明泰铝业_model_v2.json 审查日期：2026-10-15｜方法：独立重采行情与财报（东财datacenter-web），model.json逐项复算，公告口径核对，五项逻辑挑战。 纪律声明：本审查未使用券商研报与C级数字作修正依据；观点分歧均附证伪指标。

一、独立复采结果

1.1 行情（重采，与报告一致 ✓）

2026-10-15收盘14.81元、-3.2%、总市值184.13亿元、PE-TTM 7.59、PB 0.905。复算：14.81×12.4329亿股=184.13亿 ✓；184.13÷24.27（TTM归母，见下）=7.59 ✓。基准日、股本、市值、PE/PB全部核对通过。

1.2 财报关键项（重采2023–2026H1共12期，与报告一致 ✓）

  • 2024年：营收323.21亿、归母17.48亿、毛利率6.95% ✓
  • 2025年：营收351.35亿、归母19.60亿、毛利率7.08% ✓
  • 2026H1：营收211.19亿、归母14.07亿、毛利率9.75%、加权ROE 7.09% ✓
  • 2025H1归母9.4025亿 → 26H1同比+49.62% ✓；2026Q1归母7.0205亿 → Q2单季7.05亿 ✓
  • TTM归母=19.60+14.07−9.40=24.27亿 ✓，对应PE-TTM 7.59 ✓

1.3 model.json算术端点逐项复算

  • 端点乘法全部正确：17×9=153、19×11=209、21×11.5=241.5、23×13.5=310.5、25×13=325、27×15=405 ✓
  • 每股价值：153/12.4329=12.31、209/12.4329=16.81、241.5/12.4329=19.43、310.5/12.4329=24.98、325/12.4329=26.14、405/12.4329=32.58，与卡片12.3–16.8/19.4–25.0/26.1–32.6一致 ✓
  • 利润桥：155×1,100=17.05亿、160×1,350=21.6亿、170×1,500=25.5亿 ✓；股息率6.6/184.1=3.58% ✓
  • 发现一处不自洽（修正项#1）：§3.1称26H1销量≈82万吨→吨净利≈1,760元/吨，但14.07亿÷82万吨=1,716元/吨；若取1,760元则隐含销量79.9万吨。两个数只能留一个：建议改为「销量≈80万吨（C+推导）→吨净利≈1,760元/吨」，或「82万吨→1,716元/吨」。此值是三点序列的顶端，直接影响1,350中枢的取位论证，必须自洽。
  • 发现口径不一致（修正项#2）：2024年吨净利在§0/§6.1写≈1,100元、在§3.1/§8写≈1,150元。复算17.48亿÷151.6万吨=1,153元/吨。建议全文统一为≈1,150元（或写1,100–1,150区间），否则悲观档「回到2024水平=1,100」与事实略有出入，悲观档利润或可上修约0.8亿（影响<5%，不改结论）。

1.4 公告与口径重点核对

  • 26H1毛利率9.75% vs 2025年7.08%、归母+49.6%：数字属实（A级复采一致）。但需补一个报告遗漏的事实：2022年毛利率9.76%、2023年9.46%（东财XSMLL口径，报告§2表内已有2022数据但未用于论证）——即9.5%左右的毛利率并非2026H1的异常高值，而是公司2022–2023年的常态。这一点支持而非削弱中性档「毛利率9.5%可维持」的假设，报告应显性引用，作为「七成可维持」判断的第四个证据点。同时注意2024年季度毛利率曾达11–12%（2024H1东财口径12.4%）后全年塌至6.95%，说明年内毛利率波动极大，单季验证线（26Q3≥9.0%）设置合理。
  • 再生铝产能100万吨/铝板带箔160万吨：报告标注A级（2025年报），复采未获反证，通过。废铝处理能力「100余万吨」与保级应用产能「超100万吨」两个口径在正文混用，建议统一表述。
  • 出口毛利率12.16%及+9pct跳升：12.16%为2025年报A级 ✓；但对比基准「2024年出口毛利率约3.2%」是报告自称的「B级回溯推知」，正文§1表格直接写「+9.0pct」，精度似A级。修正项#3：应标注「+9pct基于回溯推知基准（B级）」，且「出口是否含转口/贸易类业务口径」年报分地区披露未拆分，列为待验证缺口（报告§11缺口清单可补此条）。不影响方向判断——韩国光阳净利1.99亿（A级）独立佐证出口利润真实性。
  • 回购与股本：报告称回购均为激励回购注销（23.3万股+18.04万股），未披露回购金额——回购金额缺口修正项#4（轻微）：应补「累计回购注销金额约X亿元（公告口径）」或明示未核实；对估值无实质影响（股本变动<0.1%）。

二、逻辑挑战（五项）

① 中性锚1,350元/吨是否站得住——部分成立，但论据需补强

三点序列1,150/1,265/1,760的中性取1,350，报告称「中枢偏上、剔除顺价」。挑战：1,350隐含2026H1改善约32%可留（(1350−1265)/(1760−1265)≈17%…按增量算仅留17%，按绝对水平算介于后两点之间），报告§4「约七成可维持」的表述与1,350的取值存在表述与数字脱节——1,350实际是保守取值，「七成可维持」指毛利率而非吨利，建议统一口径。更关键的正面证据是§二.1.4：2022–2023年毛利率常态即在9.5%一线，且2022年归母15.99亿对应销量若~135万吨则吨利约1,180元——即「毛利率9.5%+吨利1,350」组合历史上未同时出现过（2022-23高毛利低吨利，2025低毛利高吨利），1,350的隐含组合是历史未验证的新组合。中性锚不算站不住，但「加工费修复幅度」的论证目前只有高端加工费>1万元（A级）+产能爬坡两条定性证据，建议补一条量化证伪指标：2026年报吨净利<1,250元即触发中性下修至1,250/160万吨=20亿（现验证表写「<1,150触发重估」，阈值偏松，建议收紧至1,250）。

② PE 11.5–13.5x vs 现价隐含7.6x——最大薄弱点

历史中枢8–10x（报告自认），中性下沿11.5x已高于历史上沿。报告给的依据是ROE 11.5%+波动下降+股息3.6%三要素，但缺少ROIC量化（§5自认无法测算）与「加工费韧性历史」——2024年加工费战恰证明韧性不足。PB-ROE交叉验证（215–254亿）低于PE法下限241.5亿，报告自己也承认「PE法假设偏满」。判定：PE区间论证不充分，修正项#5——不是要求降PE，而是二选一：补「分红的绝对底+净现金占市值~45%（27.8亿现金+56.7亿存单 vs 184亿市值）」的硬资产论证使11.5x可辩护，或将中性区间下修至220–290亿（PE 10.5–12.5x）。报告未犯「破净=低估」替代推导的错误（PB仅作交叉验证且被指出偏满），此点通过。

③ 悲观档1,100元是否已反映双重挤压——基本充分，但传导链需复算

悲观档=2024年实际水平（加工费战），且报告另设§7压力情景800元/吨兜底「铝价回落+贸易冲击同时发生」，双层结构合理。但按skill硬规则复算压力传导链：压力档归母11.6亿=145万吨×800元，若出口毛利率从12.2%回落至5.4%，收入端减少约5.3亿毛利，费用率未同步复算——800元/吨已隐含费用压缩，需在§7显性声明「压力下费用率降至X%」或给出期间费用合计验证。悲观档本身通过。

④ 双重乐观禁令——乐观档合规，但有一处张力

乐观档25.5亿=1,500元×170万吨，报告显性声明「铝价正常化、不含顺价」，合规。但乐观毛利率10.5%高于2026H1的9.75%，而乐观同时假设铝价正常化——铝价回落通常压缩顺价空间、毛利率应承压，「铝价正常化+毛利率再升」的组合需要「高端占比30%+」单独支撑，报告有此论证（电池材放量），勉强成立，但应加一句敏感性：若10.5%毛利率无法在铝价回落中实现，乐观档利润回落至25.5亿下限，PE 13x下限对应325亿仍成立——结论稳健，通过。

⑤ 再生铝价差红利的证据等级——处理合规，占比已正确约束

报告§3.2明示「未披露自用比例与单吨成本节约额——定量缺口，明示」，且「溢价幅度不可独立计量，故不单独给估值加项」——符合C级不作修正依据的纪律。100万吨产能（A级）仅证明能力，不证明价差提取额；中性档1,350元中该红利占比未知（可能0–300元/吨），报告未虚构量化占比，通过。建议§10降级条件补一条：若2026年报仍无再生铝定量披露且吨利<1,250，「原料价差红利」从中性档叙事中降权。

三、裁定

总评：需修正（轻微），结论与B级分级维持。

需修正清单（按优先级）： 1. 26H1吨净利1,760 vs 销量82万吨不自洽（复算1716元或79.9万吨），三点序列顶端必须自洽； 2. 2024吨净利1,100/1,150两处不一致，统一为≈1,150元； 3. 出口毛利率+9pct的对比基准为B级回溯值，需降级标注，并补「出口口径是否含转口/贸易」入缺口清单； 4. 回购金额未披露，补公告口径金额或明示未核实； 5. 中性PE 11.5–13.5x论证不足：补净现金/分红硬底论证，或将中性区间下修至220–290亿； 6. §7压力档传导链补费用率同步压缩的显性声明； 7. 建议性（非错误）：中性档显性引用2022–23年毛利率9.5%常态作为第四证据；吨利证伪线从1,150收紧至1,250。

通过项：行情/财报全项复采一致；model.json端点与每股价值全部正确；归母+49.6%、Q2拆分、TTM、股息率复算无误；无源数字纪律与C级标注执行到位；双重乐观禁令有效执行；再生铝价差处理合规；PB-ROE交叉验证诚实披露了PE法偏满。

事实层错误6处（#1–#6），均为表述/口径/论证强度问题，不动摇「中性21–23亿×11.5–13.5x、中枢276亿」的结论骨架；若采纳#5的下修选项，中性中枢降至约255亿，B级评级与±赔率结构不变。
