3. 三情景估值卡片（正常化PE+周期顶折价）

方法选择：光模块是"技术迭代驱动的类周期制造业"——利润随代际(800G→1.6T→3.2T)脉冲式释放、ASP年降20-30%为常态。禁用当年PE年化、禁DCF（代际竞争格局不可外推5年）；采用正常化PE applied to 周期中继盈利（2027E）+周期顶折价。对照组口径：寒武纪按2027E 70x（成长溢价/客户集中折价）、润泽EV/EBITDA（重资产），旭创作为其中利润兑现度最高、周期性也最强的一档，给成长制造折中区间的正常化PE。 2026E基准：H1已136.5亿、Q2环比+38%；假设H2环比放缓（高基数+1.6T爬坡），2026E归母290-330亿（中性310亿，推断）；券商区间300-400亿（B级）。

4. 固定三句话

  1. 最关键假设：1.6T供需缺口至少延续到2027H2、且毛利率在40%以上有支撑——这是中性7,300亿的单一支点。
  2. 最容易错的假设：把46%毛利率当新常态——导入期稀缺溢价回归+ASP年降，2027年利润高平台的"平台"本身可能不成立（光模块历史上从无利润平台，只有脉冲）。
  3. 下一步验证：26Q3单季（2026-10月底披露）营收≥280亿且毛利率≥44%→中性成立；OCF/归母比回升至0.5以上→现金流红旗解除；反之双降即触发下调。

5. ABCD分级与触发条件

分级：B-（中性偏下）。证据强度全队列最高（敞口A级+利润兑现A+扣非干净），但现价≈中性情景（-15%）而下行尾部（-56%）含政策+技术路线+客户集中三重不可分散风险，风险补偿不对称，不足以给B。与队列对照：利润兑现强于寒武纪（C+）但寒武纪是国产替代期权、旭创是已兑现的周期峰值利润——期权给溢价、峰值给折价，两者分级接近但方向相反。

  • 升B：26Q3毛利率≥44%且OCF/归母≥0.5；或FCC禁令明确不涉及存量产品。
  • 升B+：3.2T获CSP具名定点（B级以上）+ 2027年订单能见度获公司正式指引。
  • 降C+：26Q3单季归母环比转负，或毛利率跌破40%，或OCF连续两季净现比<0.2。
  • 降C：FCC禁令正式落地覆盖公司主销产品，或第一大客户砍单公告。

7.2 时间维度四问

  1. 预测期：2026–2027（1.6T代际兑现期）；2028起3.2T/CPO路线归属不可外推（禁DCF的方法论原因）。
  2. 目标状态：2027E归母330亿平台——但"光模块历史从无利润平台，只有脉冲"（本报告三句话）；毛利率40–42%的均值回归即目标状态的诚实上限。
  3. 投资验证时间表：26Q3单季（营收≥280亿/毛利率≥44%/OCF比≥0.4三线）→ 2027订单能见度与3.2T定点 → FCC规则落地与否。
  4. 可持续性：份额与技术溢价可持续（A级五年第一口径B），但利润水平不可持续——代际脉冲+年降20–30%决定其盈利是波动路径非稳态；现价把峰值当平台定价是最大的时间维度错误。

融资约束提示：A+H双平台融资通道打开（H股2026-07-30上市，A），扩产资金充裕、摊薄渐进；现金转化的营运资本占用（应收+存货>50%资产）实质是"利润先行垫资"——若代际切换时需求回落，垫资转化为减值，这是现金流红旗与周期顶风险的叠加点。

7.3 价值兑现验证链

北美CSP capex → 1.6T订单/出货 → 收入+186% → 毛利率≥44%（扣稀缺溢价后）→ OCF/归母≥0.5（红旗解除）→ 存货应收随收入消化 → 增量ROIC维持 → 股东价值。链上当前最弱环节：利润→现金转化（净现比0.13）；禁止以"收入+186.6%/缺口四成"直接证明股东价值——峰值利润须打周期折价。
