开源中尺寸模型（Qwen 27B级）产业趋势与价值链节点研究（合并稿）

版本 v1.0 ｜ 2026-10-12 ｜ 本文合并《开源中尺寸模型_产业趋势研究.md》《开源中尺寸模型_机会节点研究.md》《开源中尺寸模型_候选企业清单.md》三份红队修正版研究为单文档，并补充本次一手核验数据（HF官方博客2026-03、Qwen3.5/3.6发布信息、DeepSeek许可条款、信通院《大模型专有云服务市场分析2026》）。 规则：基本面研究，禁技术分析。事实/推断/预测分级标注；所有关键数字带来源与时点；区分「已发生」与「推演」，自媒体臆断不作为证据。 研究边界：20-40B级（含MoE激活3-17B）开源权重模型普及后，对①算力链②云厂商③软件与服务④端侧硬件的影响。家庭常驻Agent细节归《家庭空间常驻Agent》研究，本文仅交叉引用。

0. 一句话结论

事实：开源中尺寸模型已是全球开发者默认工作流——Qwen系列累计下载超30亿次、衍生模型超30万款（彭博/HF，2026-08）；开源与闭源旗舰的性能差距已缩窄至约1.7个百分点（斯坦福AI Index 2025）；中国模型占HF下载 plurality（41%，HF官方博客 2026-03-17）。 推断：模型能力从稀缺品变为准公共品，模型层利润被开源商品化清零，价值向上（推理算力量）和向下（部署/调优/应用/端侧）两端迁移。中尺寸是私有化部署的甜点尺寸：一台4-8卡服务器或一台端侧推理盒即可承载，部署门槛从百万级降至数万-数十万级。 预测：训练算力占比趋势性下降、推理成基本盘（推理算力已占中国智算约六成，IDC×信通院 2026-06调研）；「免费权重≠免费AI」，总算力消耗不降反升（杰文斯效应），但结构上从巨头训练集群扩散为千行百业的推理部署。

1. 事实基础：开源中尺寸模型现状

1.2 跑分与能力差距

  • Qwen3.5-397B：MMLU-Pro 87.8、GPQA-D 88.4、AIME2026 91.3（vs GPT-5.2的96.7）、SWE-bench Verified 76.4（vs Claude Opus 4.6的80.9）——接近但未全面超越闭源旗舰（第三方评测汇总 nxcode/DeepInfra，B级）。
  • 开源vs闭源整体差距约1.7pct（斯坦福AI Index 2025，A级）。
  • 中尺寸量化模型的现实天花板：Qwen3-32B综合Agent任务分18.4 vs 旗舰44.8（LLM Stats，B级）——开源在常规推理上够用，在复杂Agent任务上仍明显落后，端云分工因此长期存在。

1.3 下载量/衍生模型/企业采用（一手数据）

  • HF生态2025年：1300万用户、200万+公开模型、50万+公开数据集，同比接近翻倍（HF官方博客 2026-03-17，A级）。
  • Qwen累计下载超30亿次、衍生模型超30万款；2026年2月单月下载15.4亿次，超过其余八大发布方之和（凤凰网/PANews转引彭博，2026-08，B级）。
  • 中国模型占HF下载41%（2025年，HF官方博客，A级）；2025年新trending模型多数为中国开发或中国模型衍生（同上）。
  • 采用集中度警示：HF上约半数模型总下载<200次，top 0.01%（200款）模型占全部下载49.6%——「下载量」不等于「企业采用」，媒体常混淆（HF官方博客，A级）。
  • 企业侧：超过30%的财富500强在HF有认证组织账号；Thinking Machines的Tinker完全基于开源权重；Airbnb等加大开源使用（HF官方博客 2026-03，A级）。
  • 中国私有化侧：45%央企完成DeepSeek部署（甲子光年引浙商证券，2025-02，B级）；60+厂商推出DeepSeek一体机（2025-02）；信通院《大模型专有云服务市场分析（2026年）》（2026-07-30发布，A级）：全国日均词元调用量两年增幅超千倍；大模型专有云推理服务占国内推理服务超三成份额，预计2026年底达约35%——私有化/专有云不是边缘路线，是国内推理的主承载之一。

1.4 采用结构【推断】

  • G端/央国企：过尝鲜期，进入采购部署（部分从一体机转向EP推理集群，甲子光年2025）。
  • 金融/能源强监管：数据不出域硬约束，企业自建智算云推理算力超350 EFlops、日均Token产能超70万亿（IDC×信通院 2026-02）。
  • 中小企业：预算10-50万区间，「问多买少」（甲子光年2025-02访谈）——未来3年最大增量池，也是最大不确定性。
  • C端/端侧：「端侧AI元年」叙事，中低端端侧AI芯片出货同比+110%（IDC 2026Q1报告转引），出货验证不足。

2. 对算力链的影响

2.1 训练→推理迁移【事实为主】

已披露数据（事实级）： - 推理算力占中国智算约六成，企业自建线下推理占1/3以上（IDC×信通院联合调研，2026-06）。 - 中国智能算力规模：2025年底1590 EFLOPS（FP16）→2026年3月底1880 EFLOPS（+18%/3个月）（国家数据局，经东财证券/IDC转引）。 - Token调用量：中国公有云MaaS 2024年114万亿→2025年1944万亿（16x）→2026E约4万亿亿次量级延续20x级增长（IDC 2026-05）；2026年3月全国日均Token调用超140万亿（东财证券研报）。 - 德勤：推理负载占比2023年1/3→2026年约2/3（36氪转引，B级）。 - AI服务器厂商从项目制转向常态化扩容（证券之星 2026-07-08）。

推演部分（须区分）： - 开源中尺寸普及不减少算力需求，而是重塑结构：①算力从巨头训练集群搬进千行百业的推理机房与端侧；②推理先行使国产芯片获得放量入口（推断，东财证券观点）。⚠️量级背书需谨慎：「Agent化使单任务Token消耗放大20-30倍」出自海光信息IR口径，利益相关、无第三方核验，仅作C级证据。 - 杰文斯效应的三个削弱项（红队修正，2026-10）：①智算中心利用率不足40%（亿欧智库2026-07），总量上升≠有效需求上升；②本轮云涨价含成本推动成分（腾讯业绩会：硬件成本+盈利纪律；大摩2026-08：八家平均API价较25Q1 +48%/+80%），HBM周期回落可能反转；③需求弹性有限——讯飞AI学习机因芯片/存储涨价销量不及预期。

2.2 国产芯片受益逻辑

  • 中国高端AI芯片2025年出货400万片、国产占41%（IDC）；Bernstein预测2026年英伟达在华份额降至约8%（归属Bernstein；TrendForce口径为2026年国产份额近90%——激进外推，取「结构性上行」而非点值）。
  • 华为昇腾2025年81.2万张（国产占49%）；寒武纪2026H1营收60亿(+108%)、毛利率55%；海光2026H1营收91亿(+66.5%)、DCU适配365款大模型覆盖99%非闭源模型——开源模型的可自由部署性，正是国产芯片「跑通模型生态」的前提：模型许可越开放，芯片适配壁垒越重要（适配从数月压缩到数日，DeepSeek V4 Day-0接入百余家）。
  • 竞争警示：国产GPU四小龙（摩尔线程/沐曦/壁仞/燧原）2025H2-2026密集上市，是寒武纪/海光隐含增速的直接威胁。

2.3 供需平衡判断【推断】

  • 推理算力短期仍紧缺：云厂商2026年3月起集体涨价（AI算力产品+5%~34%，阿里/腾讯/百度，财联社；腾讯混元输入价+463%后整体再提价5%、百度+5~30%、商汤+12%；DeepSeek V4-Pro高峰输出价6→27元/百万tokens即+350%，2026-08-13）。
  • 净效应：私有化分流部分云需求，但每台一体机/推理盒本身是新增硬件需求；云GPU需求增速可能被私有化分流而低于MaaS调用量增速——云厂商「量增价升」持续性需打折。
  • 「搬离云」2026年尚无证据：反向证据是腾讯2026Q2 capex 527.84亿（约528亿）（年化2000亿+）明确自研优先、阿里8月800亿港元配售全投AI基建。私有化分流的真实战场是G端/央国企预算盘子（一体机），与公有云增量是两个池子。

3. 对云厂商的影响：定价权与利润池

3.1 开源对云API定价权的侵蚀【事实+推断】

  • 开源模型免费→MaaS「模型溢价」消失，云厂商被迫赚推理吞吐、工具链和全家桶的钱（向量库/存储/安全/SLA）。火山引擎以豆包开源模型+低价拿下公有云MaaS调用量49.5%份额（IDC 2025）。
  • 矛盾现象：2026年云厂商集体涨价（见2.3）表明价格战结束、转「利润优先」——但大摩统计的+48~80%涨幅中相当部分是成本推动（HBM/内存涨价），不是需求定价权回归。

3.2 私有化 vs 云API的份额变化【事实】

一手数据： - 信通院《大模型专有云服务市场分析（2026）》（2026-07，A级）：大模型专有云服务推理服务占国内推理服务超三成份额，预计2026年底约35%；政务、金融、能源为主要落地行业；未来3~5年专有云推理服务市场保持高速增长。 - 中国公有云MaaS营收：2025年30.7亿元→2026E约186亿元（IDC口径）——公有云MaaS盘子本身还小，国内大模型服务的主要形态从一开始就偏私有化/专有云，而非美国式API经济。 - 智算云基础设施（AI IaaS）2025年486.7亿元、+128%（IDC）——云厂商的真实利润池在基础设施层而非模型API层。

企业选择私有化的真实动机（按证据强度排序）： 1. 数据合规硬约束（A级）：政务/金融/能源核心数据不出域是监管要求，与成本无关（信通院报告、新华报业选型指南2026-07一致）。 2. 调用量大的成本临界（B级）：私有化为一次性算力投入+持续运维，适合调用量大场景；腾讯云开发者社区调研（2025-06，C级、非权威）称67%大型企业倾向私有化/混合、78%中小企业选云起步——比例数据来源可信度有限，仅作方向性参考。 3. 可控性与深度定制（B级）：自选模型/版本/微调，IDC调研85.8%企业选混合架构。 4. 供给侧推力：大模型一体机把私有化门槛降到「通电即用」，泛政府类单位私有化部署服务器（一体机）开支空间约1000亿元（券商测算，浙商证券口径，推演级）。

判断【推断】：开源中尺寸是云厂商的「特洛伊木马」——客户随时可拿走模型自部署，云MaaS必须靠工具链/SLA/混合方案锁定客户；纯模型API业务毛利结构性承压，AI IaaS才是云厂商真实利润池。私有化部署市场格局分散（百度智能云、商汤、电信AI、中关村科金、创新奇智、星环等头部，IDC 2025），集中度远低于公有云——这是A股服务商的机会窗口。

4. 对软件与服务的影响

4.1 应用层成本下降→应用繁荣？

已有证据（事实）： - 交付成本侧：模型免费+一体机化，部署成本从百万级降至数万-数十万级；金山办公以垂类Agent+上下文壁垒差异化，2026H1经调整净利+18~38%、WPS AI月活8013万(+307%)——应用层能留住利润的路径已被验证（办公垂类）。 - IDC：72%企业已投产Agent（B级）。 - 但「成本下降→应用爆发」的传导并非无摩擦：推理集群调优门槛高（EP并行）、模型同质化使场景工程成为竞争点；中小企业仍「问多买少」。 - 反例警示：应用繁荣≠服务商繁荣——软通动力2026H1 AI相关收入114亿(+40%，占比61%)但归母-2.65亿、经营现金流-39.5亿；拓维信息2026H1智能计算收入-33%、扣非亏损。收入是真的，利润普遍为负或微利。

4.2 集成/微调/运维服务市场规模

  • 模型成本清零后，价值转向：交付实施（一体机集成）、行业知识库/微调、Agent编排与运维。
  • 量化锚点（多为推演/单点）：泛政府私有化服务器开支空间约1000亿元（券商测算，乐观偏差警告）；一体机采购量2025/2027预测15/72万台（浙商证券）vs 实际「问多买少」（甲子光年）——销量预测与实际销售存在落差，禁用券商预测作锚，以政采网/运营商集采中标数据为准（裁定规则：2026Q4单季央国企中标≥5万台→券商路径成立；<2万台→「问多买少」坐实）。
  • 一体机经济学：客户预算集中在10-50万；硬件同质化（都是服务器厂出货），差异化在软件调优——利润流向掌握推理引擎/调优能力的厂商，纯贴牌商赚搬运费（软通计算产品毛利率仅7.7%为证）。
  • 服务模式升级信号（信通院2026-07）：从「资源供给」向「场景交付」转型，计费从资源时长转向任务效果，「词元资产化运营」范式初现。

5. 对端侧硬件的影响（与《家庭空间常驻Agent》交叉引用）

  • 技术前提已具备：中尺寸MoE激活仅3B（Qwen3.6-35B-A3B、Qwen3.5小模型0.8-9B全开源），4-bit量化后稠密32B约需20-24GB显存——单张工作站卡或端侧芯片可跑。
  • 端侧推理芯片上限快速上移：后摩智能M50，10W/160TOPS可跑35-120B（WAIC 2026，雷科技/新浪转引）；瑞芯微RK182X支持3B/7B、RK1860将支持13B（钛媒体，B级）；高通骁龙8 Elite Gen 5端侧跑gpt-oss 20B级、220 token/s（高通官网，A级）；联想AI主机P7（30W跑122B，WAIC 2026）。
  • 需求侧：中低端端侧AI芯片出货同比+110%（IDC 2026Q1，B级）；AI PC（OPX一人公司需求160万台/2026，IDC，大盘PC仅-6.1%）；洛图科技2026年中国消费级AI硬件市场1.27万亿元（⚠️口径宽泛，含大量非LLM硬件）。
  • 交叉引用：《家庭空间常驻Agent》研究结论——家庭常驻Agent的本地化、隐私化运行以端侧中尺寸推理为算力前提；本文的瑞芯微/全志/后摩等边缘推理芯片是两个队列的共同上游，该队列的终端公司（家庭机器人等）不在本清单重复覆盖。边界判断：端侧承接20-80%轻任务（36氪深圳案例：80%任务本地完成），复杂Agent任务仍回云（见1.2天花板）——端云分工而非端侧替代。
  • 证据强度总评：端侧叙事「元年」级，出货与复购验证不足，证据多为B/C级。

6. 节点排序：谁获得增量利润，谁被商品化侵蚀

价值链：模型层（开源免费）→ 推理芯片/ASIC → 服务器/一体机整机 → AIDC/机房 → 云MaaS/AI IaaS → 部署实施与调优 → 行业应用/Agent → 端侧终端

开源中尺寸普及的结构性效应：模型层利润被清零，价值向两端迁移——向上（推理算力总量暴涨）与向下（部署、调优、行业知识、Agent编排成为模型之后的价值捕获点）。

被商品化侵蚀的环节（反直觉但同样重要）： 1. 闭源模型API的纯模型溢价——开源旗舰差距仅1.7pct且许可完全商用，模型本身是最先被商品化的环节。反例压力测试：闭源厂靠推理质量代差（复杂Agent任务）与多模态前沿维持溢价窗口，但窗口在收窄。 2. 纯贴牌一体机商——硬件同质化，毛利率被压至个位数。 3. 无调优能力的纯算力租赁商——推理优化进步侵蚀其毛利。例外（观点分歧）：具备大模型客户长协+Token定价能力者不在此列——行云科技2026-07算力合同已出现Token收入挂钩定价（5年10.14→30.53亿、单价上调21-36%）。 4. 中游整机毛利率结构性低——被上游芯片和下游大客户两头挤压（浪潮毛利率4.91%，2025前三季）；真正的高毛利在芯片（寒武纪55%）和有场景粘性的应用（金山办公86%）。

利润流向的时间结构【推断】： - 已兑现（2025-2026报表可见）：A芯片、B服务器、H机房——确认性最高，估值已部分反映。 - 正在兑现：C一体机、D部署服务——收入可见、利润未到，买收入质量不买收入规模。 - 期权型（2027+）：E垂类Agent盈利扩散、F端侧放量、G PC结构变量、I Token工厂。
