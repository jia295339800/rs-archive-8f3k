开源中尺寸模型：产业深度研究报告（定稿）

研究主编整合定稿：2026-10-12 估值/行情基准日：2026-10-09（东财 datacenter + 新浪行情，脚本采集）；财务数据截至 2026-06-30 报告期（2026-10-12 红队独立复采） 整合来源：《开源中尺寸模型_产业趋势与节点研究.md》（合并稿 v1.0）、《06_估值与分级/开源中尺寸模型_核心企业估值报告.md》（v1.0）、《09_红队审查/开源中尺寸模型_红队审查.md》（v2，2026-10-12） 红队状态：红队 v2 已完成独立复采与口径溯源；本轮主编修订后残余为观点分歧（零事实错误目标见第九章分歧清单），归 W4 监控工作流以真实数据裁决。 规则：所有关键数字标来源/口径/时点；全部结论带【成立/修正/存疑】标签；观点分歧不强行统一，单列第八章。

〇、核心结论（先说立场）

  1. 产业事实层【成立，两处口径修正】：开源中尺寸模型已是全球开发者默认工作流（Qwen 累计下载超 30 亿次、衍生模型超 30 万款，彭博/HF 2026-08，B级）；开源许可（Apache 2.0/MIT）无商用门槛是私有化爆发的法律前提【成立】。但两条旗舰级数字必须带修正口径引用：①"中国模型占 HF 下载 41%"是博客宽口径，底层数据论文（Economies of Open Intelligence, arXiv:2512.03073）近期下载口径中国仅 17.1%（vs 美国 15.8%），宽/窄口径差 2.4 倍【修正】；②"开源 vs 闭源差距 1.7pct"是Chatbot Arena 旗舰口径、2025-01 时点，中尺寸量化模型在复杂 Agent 任务差距仍达 2.4 倍（Qwen3-32B 18.4 vs 旗舰 44.8，LLM Stats，B级）【修正】。
  2. 价值迁移【修正：方向维持、当期证据一半】："模型层利润被开源商品化清零"降级为远期推断——2025-2026 可观察周期内，模型 API 层正经历量价齐升（八家平均 API 价较 25Q1 +48%/+80%，大摩 2026-08；腾讯业绩会明言令牌业务正向毛利），"清零"在当期利润表被反证一半【修正】。真实被商品化的当前是"纯模型许可售价"（本就为零）而非"模型服务利润"。
  3. Token 叙事→个股归因【修正：归因链断于第一环】："16x"的真实出处是信通院调研（基数 IDC）2026-03-26 文：公有云对客侧 Token 2025 年约 2000 万亿 vs IDC 2024 年 114 万亿（原报告误记"IDC 2026-05"，归属更正）；且该口径只度量公有云 MaaS——整个盘子中最小的一块（2025 年营收仅 30.7 亿，IDC）。三家核心标的收入的第一驱动分别是：寒武纪=国产替代（政策时点证据）、海光=CPU 信创（收入大头）、润泽=第一大客户 capex（推断字节，C级），三家均无"推理 vs 训练"收入拆分披露【修正，存疑保留】。
  4. 企业结论（评级经红队 v2 修订）：
  5. 浪潮信息 A- → B（观察）【修正】："唯一市场未给 AI 定价"论据撤销——H1 毛利率 8.7% 的修复主要是从 2025 年 4.9% 历史低谷向 2024 年 7-8% 正常水平回归 + 成本转嫁，SOTP 中 540 亿"AI 增量"大部分可被非 AI 因素解释。升级条件改为"26Q3 单季毛利率 ≥9.5% 且收入增速 ≥15%"。
  6. 寒武纪 C+（维持）【修正：口径】："两年 54 倍"为基期+时间单位错配（2024 全年 11.7 亿 vs 2026H1 单季 60 亿），正确口径为 2024→2026E 约 9-10 倍，其中 2025 年 5.6 倍；高增长方向不变（2025 +453%、2026H1 +108% 为真）。
  7. 金山办公 B- → C/C-【修正】：+237% 定案为非经常项主导（单季拆分：2026Q1 归母 21.95 亿、单季净利率 136%；Q2 单季仅 3.23 亿、与 2025Q2 的 3.4 亿持平——H1 净利增量约 99% 发生在 Q1）。剔除异常后主业年化约 13-14 亿，真实 PE 约 75x；"应用层利润已验证/价值向下迁移已被验证"论据撤销——其利润表恰恰证明应用层 AI 变现未在报表兑现。
  8. 海光信息 B+（维持，观点分歧）【存疑】：162x PE-TTM 下"已充分定价"与"净利率正常化期权"并存，双方证伪指标见第八章。
  9. 中科曙光 B（事件驱动）、润泽科技 B、金蝶国际 B+（参照）、润建股份 D（反例）：维持原评级【成立】。
  10. 一句话总判断：开源中尺寸的方向逻辑（推理算力放量+私有化/专有云承载）在报表端已兑现于芯片与承载层，但兑现的第一驱动是国产替代/信创/大客户 capex 而非"开源推理"本身；价格端已大幅预付，应用层的"下半场"至今没有任何一家 A 股公司拿出收入级 AI 披露——向下迁移仍是期权而非现金流。

一、产业事实层（含红队口径修正）

1.1 模型谱系与许可【成立】

核心事实不变（一手核验，A级）：Qwen3-32B / Qwen3-30B-A3B（Apache 2.0，2025-04）；Qwen3.5-397B-A17B（2026-02-16，Apache 2.0）；Qwen3.6-35B-A3B（2026-04-19）；DeepSeek-V3.2 及 R1 蒸馏系（MIT）；Llama 4 / Gemma 3 许可有条件限制。Qwen/DeepSeek 系完全商用许可是 G 端与产业资本私有化部署的法律前提【成立】。

1.2 下载量与采用结构【修正一处口径】

  • HF 生态 2025 年：1300 万用户、200 万+公开模型、50 万+数据集（HF 官方博客 2026-03-17，A级）【成立】。
  • "中国模型占 HF 下载 41%"【修正】：必须加注宽/窄口径。41% 为博客宽口径（含中国模型的全部衍生/量化/转存仓）；底层论文《Economies of Open Intelligence》（85.1 万模型、22 亿次下载、2020-06~2025-08）近期下载口径：中国 17.1%、美国 15.8%——微弱领先而非 plurality。两口径差 2.4 倍，引用时必须双口径标注。
  • "超过 30% 财富 500 强有 HF 认证组织"【修正：降 C 级待验】，红队未能在原文证实，不得作 A 级引用。
  • 自挂警示保留【成立】：约半数模型总下载<200 次、top 0.01%（200 款）占全部下载 49.6%、平均活跃期约 6 周——"下载量≠企业采用"。
  • 信通院《大模型专有云服务市场分析（2026）》（2026-07-30，A级）：专有云推理服务占国内推理服务超三成、2026 年底约 35%【成立，逐字证实】；"日均词元调用量两年超千倍"句未能证实，降 C 待验【修正】。

1.3 性能差距【修正：口径必须并列】

  • "开源 vs 闭源差距约 1.7pct"【修正】：出处为斯坦福 AI Index 2025，原始口径是 Chatbot Arena（LMSYS）旗舰级模型 Elo 差距，时点 2025-01（距今 21 个月），单一评测维度、旗舰对旗舰。正式表述："Chatbot Arena 旗舰口径 1.7pct（2025-01）；中尺寸量化模型在复杂 Agent 任务差距仍 2.4 倍（18.4 vs 44.8）"。私有化场景的真实能力差距远大于 1.7pct，端云分工因此长期存在【成立】。

1.4 算力与 Token 总量【修正：归属与口径】

  • 推理算力占中国智算约六成（IDC×信通院 2026-06）【成立】；智算规模 2025 年底 1590 EFLOPS→2026 年 3 月底约 1880 EFLOPS（国家数据局，+18%/3个月）【成立】。
  • Token 16x【修正：归属更正】：正确表述为"信通院调研（基数 IDC）：公有云对客侧 Token 调用量 2024 年 114 万亿→2025 年约 1944/2000 万亿（16 倍）"（信通院秦思思 2026-03-26 文），非"IDC 2026-05"。且该口径仅为公有云 MaaS 对客侧调用量——国内大模型服务主形态是私有化/专有云（信通院：推理份额超三成→35%），16x 度量的是整个盘子中最小的一块，不可用于为私有化链条公司背书【修正】。
  • "Agent 化使单任务 Token 消耗放大 20-30 倍"【存疑】：海光 IR 口径，利益相关无第三方核验，C 级。
  • 杰文斯效应三削弱项保留【成立，带削弱项引用】：①智算中心利用率不足 40%（亿欧智库 2026-07）；②涨价含成本推动成分（腾讯业绩会：硬件成本+盈利纪律；大摩 +48%/+80%）；③需求弹性有限（讯飞学习机销量不及预期）。

三、企业层与估值整合（红队 v2 修订后）

3.1 浪潮信息（000977）：A- → B（观察）【修正】

  • 撤销"唯一未给 AI 定价"。红队独立复采毛利率全序列：2022 年 11.2-12.3% → 2023 年 9.7-12.7% → 2024 年 6.7-8.1% → 2025 年 4.5-4.9%（四年最低谷） → 2026Q1 6.64% → 2026H1 8.75%。H1 的 8.7% 仅回到 2024 年正常水平，仍比 2022-2023 低 2-4pct——修复主体是低谷向正常的回归，叠加内存/HBM 涨价周期的成本转嫁；公司无分部毛利率披露，"AI 驱动"与"成本传导"无法区分。SOTP 中"AI 增量 540 亿（30 亿增利×18x）"大部分可被非 AI 解释，该 SOTP 作废【修正】。
  • 维持部分【成立】：收入+5.2% vs 净利+270% 的"利润率而非收入"路径判断；OCF -5.10/股、存货>500 亿的重营运资金风险；90 亿定增（27 亿补流）。
  • 新升级条件：26Q3 单季毛利率 ≥9.5% 且收入增速 ≥15%（双向证伪指标见第八章）。基准情景由 +37% 下修至约 0%~+15% 区间（正常化毛利率 7-8% 口径，估算）。

3.2 寒武纪（688256）：C+ 维持，口径修正【修正：54 倍→9-10 倍】

  • "两年收入 54 倍"作废：2024 全年 11.7 亿（前三季仅 1.9 亿、Q4 单季 9.8 亿）对 2026H1 单季 60 亿，是全年基期对半年单期的时间单位错配 + 上市后最低谷基期双重粉饰（历史教训：基期/时间单位错配类，寒武纪 54 倍即实例）。正确口径：2024→2026E 约 9-10 倍（年化 110-120 亿），其中 2025 年 5.6 倍、2026E 约 1.8 倍【修正】。方向不变：2025 +453%、2026H1 +108% 为真【成立】。
  • 维持部分【成立】：收入-毛利（55.3%±1）-OCF（+0.50/股转正）三拐点；PS 38x/PE-TTM 186x 估值透支；竞争风险（四小龙+昇腾）；"好公司、贵价格"结论维持，基准情景 -15%。

四、"模型层利润清零"命题的降级【修正】

  • 原命题（一句话结论）："模型层利润被开源商品化清零，价值向两端迁移"。降级为远期推断：

  • 付费流向：企业为"开源模型的托管推理"持续付费（专有云推理份额三成→35%），付费流向云/专有云服务商，"价值离开模型层"未发生。

八、待验证分歧清单（六项，双方逻辑并列，归 W4 监控裁决）

分歧 1：浪潮"AI 定价论" vs "正常化回归+成本转嫁"【观点分歧，双向证伪指标】

  • 正方（AI 定价）：H1 毛利率 8.7% 创 2023 年以来新高，AI 服务器结构改善+液冷/整机柜溢价真实存在；在手订单 350 亿待转化。
  • 反方（红队，本轮采纳）：基期 4.9% 是四年最低谷，修复主体是回归 2024 年 7-8% 正常水平；同期内存/HBM 涨价提供成本转嫁解释；无分部披露。
  • 证伪指标（双向）：26Q3 单季毛利率 ≥9.5% 且单季收入增速 ≥15% → AI 定价论成立、升回 A-讨论；毛利率回落至 7% 以下 → B（观察）维持甚至降 C+。

分歧 2：海光"净利率正常化期权" vs "红海定价确认"【观点分歧】

  • 正方（定价已充分，B+ 维持）：162x PE-TTM 已计价基准情景；毛利率四年连降（65.6→55.2%）说明 DCU 以价换量、AI 加速卡红海化。
  • 反方（期权论）：净利率 17.7-19.8% 显著低于寒武纪（31.7-38.5%），若向 25-28% 正常化，2027E 净利上修至 70-90 亿；2025 全年已 +57%、2026H1 +66.7%，高增是连续现象且 CPU 信创基本盘稳定。
  • 证伪指标（双向）：2027H1 净利率回升至 25%+ 且 DCU 份额披露 → 期权论胜、"已充分定价"证伪；毛利率续降 3pct+ → 红海定价确认、降 B。

分歧 3：芯片双雄是否"实质透支"（终值 PE 敏感性）【观点分歧】

  • 25x 终值下隐含 CAGR 65%/52% 无容错（透支）；40x 终值下寒武纪中性翻转为 +9%（未透支）；2026E 基数下隐含 CAGR 降至 35-40%。
  • 证伪指标：2027 年单季增速降至 40% 以下且毛利率同步下行 → 透支兑现；增速仍 >80%（供给瓶颈主导）→ 25x 偏保守。
  • 双方一致点：2026H1 净利率 38.5% 处历史高位，均值回归方向对两者都不利。

分歧 4：一体机"问多买少" vs 券商放量预测【证据不足（正方）】

  • 39 万台（2026）有第二来源（亿欧）；72 万台（2027）无第二来源；"问多买少"是 2025-02 访谈快照、时点 20 个月。
  • 裁定源唯一：政采网/运营商集采中标数据，季度跟踪。2026Q4 单季央国企中标 ≥5 万台 → 券商路径成立；<2 万台 → "问多买少"坐实，智微智能等降 D。

分歧 5：模型层商品化——远期结构论 vs 当期量价齐升【观点分歧】

  • 正方：许可免费终将商品化模型服务，价值两端迁移。
  • 反方（本轮采纳一半）：当期 API 量价齐升+正毛利反证"清零"；被商品化的只是本就为零的许可售价。
  • 证伪指标：HBM 周期回落后 API 价格不回吐（需求定价权确认）→ 结构性商品化论复活；价格回吐 30%+ → 本轮为成本周期，"清零"为伪命题。

分歧 6：杰文斯效应——结构性拐点 vs 成本周期【观点分歧】

  • 正方：Token 16x+推理占智算六成=结构性需求拐点。
  • 反方：智算中心利用率 <40% 说明总量≠有效需求；涨价含成本推动；需求弹性已现（讯飞学习机）。
  • 证伪指标：智算中心平均利用率 2027 年回升至 55%+ → 结构性成立；停留 <45% 且 HBM 回落带动 API 降价 >30% → 周期论成立。
