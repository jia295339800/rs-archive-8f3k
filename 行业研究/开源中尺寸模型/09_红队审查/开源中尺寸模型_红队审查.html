一、HF 博客与信通院数字核查

1.1 HF《State of Open Source: Spring 2026》——博客真实存在，但「41%」口径脆弱【证据不足，原标 A 级应降级】

  • 博客真实性：成立。huggingface.co/blog/huggingface/state-of-os-hf-spring-2026，署名 Avijit Ghosh 等 4 人，2026-03-17，13M 用户/200 万+模型/50 万+数据集/top 200 模型占 49.6% 下载均可在原文证实。（A）
  • 「中国模型占下载 41%」的口径问题：该博客的底层数据是其链接论文《Economies of Open Intelligence》（85.1 万模型、22 亿次下载、2020-06~2025-08）。论文近期下载口径：中国 17.1%、美国 15.8%、International/Online 23.8%——中国仅以 1.3pct 微弱领先美国，远非 41%。41% 是博客宽口径表述（含中国模型的全部衍生/量化/转存仓），转述方（getaibook 等）已明确区分两个口径。正方将其标 A 级用作"中国模型 plurality"核心事实，必须加注"宽口径 41% vs 论文近期口径 17.1%"，否则高估 2.4 倍。（B，多源交叉）
  • 「30% 财富 500 强有 HF 认证组织」未能在本次检索中证实——HF 原文可见部分与多家转述均未含此句。降 C 级待验，不得作 A 级引用。（C）
  • 另发现转述间自相矛盾：一转述称 13M 用户、另一转述称 11M——引用时以博客原文为准。（B）
  • 自挂警示仍是本报告最有用的一条（半数模型下载<200 次、top 0.01% 占 49.6%、平均活跃期约 6 周）——"下载量≠企业采用"，正方保留正确。（A）

1.2 信通院《大模型专有云服务市场分析（2026）》——「超三成/35%」成立【通过，A 级维持】

  • secrss（安全内参）转载信通院官方发布稿原文证实："大模型专有云服务推理服务占国内推理服务超三成市场份额""预计到 2026 年底专有云推理服务占比约 35%""未来 3~5 年保持高速增长"，与正方引用逐字吻合。发布主体为中国信通院云计算与数字化研究所，覆盖百余家龙头企业调研。（A）
  • 但"全国日均词元调用量两年增幅超千倍"一句未能在信通院发布稿可见部分证实——正方把它记在同一报告名下（§1.3）。已独立证实的是信通院秦思思 2026-03-26 文章：公有云对客侧 Token 2025 年约 2000 万亿 vs IDC 2024 年 114 万亿（超 16 倍）——这是"16x"的真实出处，且归属应为"信通院调研（基数 IDC）"，正方写"IDC 2026-05"属归属混淆。「千倍」表述待验，降 C。（B）

1.3 「开源 vs 闭源差距 1.7pct」口径核查【证据不足：口径未注明】

1.7pct 出自斯坦福 AI Index 2025，其原始口径为 Chatbot Arena（LMSYS）上旗舰级开源与闭源模型在特定时点的 Elo 差距（2025 年 1 月），而非"整体差距"。正方写"开源 vs 闭源整体差距约 1.7pct"漏掉：①单一评测维度（竞技场偏好，非全部任务）；②旗舰对旗舰（不含中尺寸量化模型）；③时点 2025-01（距今 21 个月）。正方自己的 1.2 节同页引用了反例（Qwen3-32B Agent 任务 18.4 vs 旗舰 44.8，差距 2.4 倍）——两处并用却只把 1.7pct 标 A 级写入一句话结论，属选择性口径。【更正：应表述为"Chatbot Arena 旗舰口径 1.7pct（2025-01）"；中尺寸量化模型在复杂 Agent 任务差距仍达 2.4 倍，私有化场景的真实差距远大于 1.7pct】。（A，口径级）

二、估值挑战逐项裁定

2.1 浪潮信息 A-「唯一未给 AI 定价」——论据不成立，毛利率修复主要是正常化回归【证据不足，降 B/观察】

独立复采毛利率全序列（东财，累计口径）：2022 年 11.2-12.3% → 2023 年 9.7-12.7% → 2024 年 6.7-8.1% → 2025 年 4.5-4.9%（历史最低谷） → 2026Q1 累计 6.64% → 2026H1 8.75%。三个反方事实： 1. 基期是异常低谷：分母 4.9% 取自 2025 全年（公司近四年最低），2026H1 的 8.7% 仅回到 2024H2-2024Q1 水平，仍比 2022-2023 低 2-4pct。把"回归正常"计入 SOTP 的「AI 增量」（30 亿增利×18x=540 亿）是把均值回归包装成 AI 期权——若正常化毛利率取 7-8%（2024 年水平），AI 增量仅剩 0-1pct。（A，财报序列） 2. 驱动归因无分部证据：正方自己承认"AI 需求爆发在浪潮报表上表现为价差而非量增"（收入仅+5.2%）。2026 年内存/HBM 涨价周期中服务器毛利率回升，竞争性解释至少有三个：①前期低价订单出清；②提价转嫁（成本推动，非需求定价权）；③结构变化。公司无分部毛利率披露，「AI 驱动」与「金属价/成本传导」无法区分——按"利益相关归因需第三源"规则应降 C。 3. 单季波动大：Q1 累计 6.6% → H1 8.75%（Q2 单季约 9.9%），波动与 2022-2024 年的季度摆幅同量级，两季维持≥7.5% 的升级触发条件正确但尚未满足。 裁定【证据不足】：A- 的"+37% 隐含回报"建立在 AI 增量 540 亿之上，该 540 亿大部分可被"正常化回归+成本转嫁"解释。可证伪指标：Q3 单季毛利率≥9.5% 且收入增速回升至 15%+ → AI 定价论成立；毛利率回落至 7% 以下 → A- 降 B。

2.2 寒武纪「两年收入 54 倍」——基期选择粉饰，成立【事实错误（口径级）】

复采：2024 全年营收 11.7 亿（其中前三季累计仅 1.9 亿，Q4 单季 9.8 亿）；2025 全年 65.0 亿；2026Q1 28.8 亿、2026H1 60.0 亿。检验： - 54 倍 = 2024 全年 11.7 vs 2026H1 单季 60——全年基期对半年单期，时间单位错配。同口径应为：2024 全年 vs 2026 年化（约 110-120 亿）≈ 9-10 倍。 - 基期取 2024 全年又恰是公司上市后最低谷（2023 年营收约 7 亿量级但 2024 前三季断崖至 1.9 亿后靠 Q4 拉回）。若取 2023 全年基期，两年约 15 倍；正确逐年读数：2025 年 5.6 倍、2026E 约 1.8 倍。 - 估值文档第 3.3 卡片与 §2 表两次使用"两年 54 倍"作为"Token 叙事兑现度最高"证据，属双口径混用（历史教训⑤重犯）。更正：54 倍算术成立但口径误导，正式表述应为"2024→2026E 约 9-10 倍，其中 2025 年 5.6 倍"。不影响"高增长已兑现"的方向判断（2025 +453%、2026H1 +108% 为真）。（A）

2.3 润泽 REITs 一次性收益——计算复核通过【通过，幻觉结论维持】

复采单季拆分：2025H1 归母 8.82 亿 → Q3 累计 47.04 亿（单季 38.2 亿）→ Q4 单季 3.5 亿；全年 50.50 亿 vs 业绩预告扣非 18.8-19.8 亿 → 一次性收益约 31 亿集中确认于 2025Q3。交叉验证：Q3 单季 38.2 亿 - REITs 约 31 亿 ≈ 7 亿扣非单季，与 H1 扣非节奏（5-8 亿/季）吻合；Q4 单季 3.5 亿正常。2026H1 归母 12.0 亿（+36.4%）、无 REITs 干扰。v1 红队报告 E9 指出的"累计当单季"错误在估值报告 v1.0 中已改对（"Q3 累计 47 亿"表述正确）。「PE-TTM 17.9x 是幻觉、扣非约 32x」结论复核成立（962 亿/2026E 扣非 30 亿 = 32x）。（A） 小瑕疵：v1 红队称"Q4 单季仅 3.5 亿（正常）"——3.5 亿较 2025Q1-Q2（4.3/4.5 亿）偏弱，Q4 扣非可能低于 3 亿，2025 扣非 19.3 亿中含 REITs 项目外的其他非经常，2026E 扣非 30 亿隐含 +55% 依赖 AIDC 继续放量，基准不保守但不失真。（A）

2.4 金山办公 +237% 非经常项——可定案：非经常项主导，疑点解除为事实【升级裁定】

单季拆分（复采）：2026Q1 归母 21.95 亿（营收 16.1 亿，单季净利率 136%，必含大额非经常/投资收益）；2026Q2 单季 = H1 25.18 - Q1 21.95 = 3.23 亿，与 2025Q2 的 3.4 亿基本持平。即 H1 净利增量约 17.8 亿中，约 17.7 亿（99%）全部发生在 Q1，Q2 主业零增长。金额约 18 亿占 H1 归母 70%+，来源几乎必为投资收益/公允价值变动（扣非明细未披露前来源属性留 C 级，但"非经常项主导"本身可定案）。裁定：估值报告的"高度疑似"应改为"已证实（单季拆分）"；B- 评级下的"正常化 NP 22-26 亿"偏低——剔除 Q1 异常后主业年化约 13-14 亿（H1 扣非口径估计），真实 PE 约 75x 而非 40-48x，金山办公应降 C/C-，"应用层利润已验证"论据（§4.1、节点 E "B+"）同步削弱：其利润表恰恰证明应用层 AI 变现没有在报表兑现。（A 计算 / C 来源属性）

2.5 海光「已充分定价」——反方证据两条成立，结论改「观点分歧」【观点分歧】

反方证据（复采支持）： 1. 净利率异常低，正常化空间大：2026H1 净利率 19.8%、2025 全年 17.7%，同期寒武纪 38.5%/31.7%。海光 TTM 归母 31.4 亿若净利率向 25-28% 正常化（收入 150-160 亿），2027E 净利可达 45-50 亿之上、乐观 70-90 亿——正方基准"2027E 60 亿×85x"自洽，但悲观 55 亿×55x 的净利率假设（约 34%，收入 160 亿）反而要求净利率大幅扩张，情景假设方向自相矛盾。 2. 增速非 2026 新增：2025 全年已 +57%（91.6→143.8 亿），2026H1 +66.7% 仅小幅加速——高增是 2025 年起的连续现象（禁运下国产替代+信创双驱动），"AI 收入敞口+66.5%"不能全部记在推理/DCU 头上（CPU 信创是"收入大头"——正方自己在 3.1 承认），而 CPU 信创增速与"开源推理"叙事无关。 维持正方的部分：毛利率四年连降（65.6→55.2%，复采证实）是真实的以价换量信号，OCF H1 转负为真。 裁定【观点分歧】：162x PE-TTM 下"已充分定价"与"净利率正常化期权"并存。可证伪指标：2027H1 净利率回升至 25%+ 且 DCU 份额数据披露 → 正方"定价充分"被证伪；毛利率续降 3pct+ → 反方（红海定价）确认。

三、「Token 16x」叙事→个股收入归因链核查【证据不足：归因链断于第一环】

叙事链：Token 调用量 16x（信通院/IDC）→ 推理算力需求暴涨 → 寒武纪 54 倍/海光+66.5%/润泽+50% 收入归因于推理。逐环检验： 1. 16x 本身成立但口径是"公有云对客侧 MaaS 调用量"（114→1944/2000 万亿），不是全社会 Token 或算力需求。而正方 §3.2 自己指出"国内大模型服务的主要形态偏私有化/专有云"，公有云 MaaS 2025 年营收仅 30.7 亿——16x 度量的是整个盘子中最小的一块，用它为私有化链条公司（一体机/AIDC/国产芯片）背书是口径错位。 2. 寒武纪：收入爆发始于 2024Q4-2025（+453%），与出口管制下国产替代（训练集群为主）时间吻合；公司无"推理 vs 训练"收入拆分披露。归因"开源推理"无直接证据，归因"国产替代"有政策时点证据。至少 50% 的增长更可能来自替代而非推理结构迁移（C 级判断，方向可辩）。 3. 海光：CPU 信创是收入大头（正方自认），+66.5% 中推理 DCU 贡献无拆分。 4. 润泽：AIDC +50% 驱动客户推断为字节（C 级），字节的算力需求含预训练+推理，且其 capex 与"开源中尺寸"无必然联系（闭源厂商同样建 AIDC）。 5. 浪潮：正方已诚实改判"兑现为价而非量"——通过。 裁定【证据不足】：估值报告 §5 的兑现表把三家收入统一挂到 Token 叙事下，归因链每一环（16x→推理占比→个股收入）都缺公司披露级证据。可证伪指标：①寒武纪/海光若在业绩会披露推理收入占比>50% → 链条补全；②IDC MaaS 30.7→186 亿若证实 → 公有云推理链条直接受益者是云厂商与 ASIC，而非这三家；③智算中心利用率<40%（亿欧）若持续 → 16x 调用量与硬件采购量的背离扩大，芯片厂收入领先于真实推理负载。

四、「模型层利润被开源商品化」核心判断的反方证据【观点分歧：当前周期内被证伪一半】

正方判断：模型层利润清零，价值向算力/应用两端迁移。反方证据（2026 年可查）： 1. 闭源/开源 API 集体涨价且维持正毛利：腾讯混元输入价+463% 后再提价、百度+5~30%、商汤+12%、DeepSeek V4-Pro 高峰输出 6→27 元/百万 tokens（+350%）；腾讯业绩会明言"令牌底层生产成本极低、令牌业务仍正向毛利"；大摩统计八家平均 API 价较 25Q1 +48%/+80%。若模型层利润真被清零，无法解释 API 价格全面上行——实际定价权当前在算力供给瓶颈侧，模型 API 毛利为正，"商品化"尚未发生在利润表上。 2. 开源免费 ≠ 免费替代：HF 报告自挂集中度证据（top 200 占 49.6%、平均活跃期 6 周）+ 专有云推理占三成且将升至 35%——企业实际为"开源模型的托管推理"持续付费，付费流向云/专有云服务商而非"价值离开模型层"。 3. 闭源厂收入侧无萎缩证据：国内多家云厂商"AI 相关收入三位数增长"（信通院秦思思文）；闭源旗舰在复杂 Agent 任务维持代差（正方自引 18.4 vs 44.8）。 裁定【观点分歧】：正方判断在"远期结构"上可辩（许可免费最终压低纯模型溢价），但在 2025-2026 可观察周期内，模型层（含开源模型的托管服务）正经历量价齐升而非利润清零；被商品化的当前是"纯模型许可售价"（本就为零）而非"模型服务利润"。产业文档 §6 已列出该反例压力测试但一句话结论（§0）仍写"清零"——一句话结论应降级为推断并加"当前周期 API 量价齐升的反例"。（B） 可证伪指标：HBM 周期回落后 API 价格若不回吐（需求定价权确认）→ 正方"结构性清零"部分复活；若价格回吐 30%+ → 本轮为成本周期，模型层利润随周期波动而非被开源清零。
